## 1. 監査方針

対格形であることと、目的語・補語・副詞的要素などの統語機能を区別する。動詞の項構造、不定詞との関係、句のまとまりを確認し、格形や語彙リストだけから機能を確定しない。

## 3. 横断的な問題

1. **目的語と格形**：対格は目的語の有力な標識だが、前置詞支配・不定詞の主語・補語・副詞的用法がある。定形動詞の存在と前置詞非支配だけでは直接目的語を確定できない。
2. **二重対格**：人物＋事物と目的語＋補語は、単に対格句が2つあるという条件では区別できない。動詞の語彙的項構造と句の意味役割が必要。
3. **不定詞構文**：不定詞の意味上の主語と述語対格は同じ構文内に共起し得る。候補の相互排他を前提にせず、各語の構文上の役割を分ける。
4. **同族対格**：同根語彙ペアは候補抽出に有用だが、同根性だけで統語機能を決めず、目的語性・様態・結果などとの関係を確認する。
5. **副詞的対格**：定型語彙リストだけでは用法を一般化できない。MAT 26:45 は章ファイルを取得できず、本文形態の照合を保留した。

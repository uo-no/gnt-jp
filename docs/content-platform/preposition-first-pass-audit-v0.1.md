## 3. 初回に判明した問題

### 3.1 「固有前置詞＋格」の3タイプは構文の記録であり、意味分類ではない

3タイプはいずれも「前置詞レンマが固有リストにあり、目的語がその格である」ことで決まる。ἐκ＋属格が「分離」を表すといった意味の分類は、設計通り格カテゴリ側（属格の分離など）が担っている。独立体系では、この3タイプは用法タイプではなく、前置詞の構文記録（レンマ×支配格）として保持し、意味は格側と前置詞側の組み合わせで読む形が適切である。MRK 1:10 のように、同じ前置詞句に種別タイプ（proper_with_genitive）と機能タイプ（adverbial_pp）が同時に立つのは、軸が違うため正当だが、軸の明示が要る。

### 3.2 adverbial_pp は必須条件がなく、判定根拠が機能と無関係

`preposition.adverbial_pp` には required_signals が設定されておらず、唯一の条件は `NOT prep_has_article()`、すなわち「前置詞の直前に冠詞がない」ことである。これは「冠詞＋前置詞句」という限定的／名詞的パターンでないことを示すだけで、前置詞句が動詞や文を修飾する（副詞的である）ことの根拠にはならない。冠詞を伴う副詞的前置詞句も普通に存在する。

前置詞句の機能は係り先（何を修飾するか）で決まる事柄であり、判定には依存関係の情報が要る。現行の条件では独立タイプとして立てられないため、unresolved として残す。係り先ベースの判定を導入するかどうかは Pass C の設計判断である。

### 3.3 improper は補集合による語彙クラス

非固有前置詞は、固有前置詞18語のリストに「含まれない」ことで定義される。閉じた語彙クラス同士の補集合なので、残余クラス（理由の ὅτι など）とは性質が違うが、境界の問題は残る。ἕως のように接続詞としても働く語、χωρίς のように副詞的にも使われる語があり、「前置詞として使われている」ことの判定は格支配の確認に依存する。現行条件は属格支配を必須としており、属格以外を取る非固有前置詞の例は拾えない。

### 3.4 substantival_pp は名詞句構文カテゴリと重なる

冠詞＋前置詞句の名詞化は、名詞句構文監査で「既存カテゴリに受け皿がない」と記録した対象だが、実際にはこのタイプが受け皿になっている。名詞句構文の substantival_phrase と句レベルで二重に記述されているため、独立体系ではこちらに一本化するのが自然である（名詞句構文側の台帳所見を本メモで訂正・補足する）。

## 4. 検出ロジックの初回所見

1. **格支配の確認は目的語の格を見る**：`prep_object_case` は前置詞の後方の目的語の格で判定する。構文記録としては再現性が高い。
2. **限定的／名詞的の分岐には工夫がある**：`pp_article_head` は冠詞と一致する主名詞を前後に探し、主格冠詞と呼格名詞の交替（MAT 6:9 型）を許容する。見つからなければ名詞的用法側が立つという設計で、保守的な注記（目的語句との区別が付かない場合は検出しない）も実装側に明記されている。
3. **機能判定の非対称**：限定的・名詞的は冠詞パターンを積極条件に立てる一方、副詞的だけが消極条件（冠詞パターンでないこと）に依存している。3.2 の問題はこの非対称に由来する。

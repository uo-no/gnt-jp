- Date: 2026-10-30
- Scope: `syntax-registry.json` の nominative カテゴリ全10タイプ
- Corpus: `public/bible_data/nt/{BOOK}/{CHAPTER}.json` on `main`
- Review status: first-pass; no production changes

## 1. 監査方針

主格の形態と、主語・述語・同格・呼びかけ・独立句などの機能を分離する。特に不変化固有名詞、中性形の主格・対格同形、無動詞文では、形態タグや節境界の扱いに注意する。

## 3. 横断的な問題

1. **主語と主格**：不変化語 Ἀβραάμ はコーパスで N-PRI とタグ付けされるが、文中では主語として機能する。形態格と統語機能のデータモデルを分離する必要がある。
2. **述語主格**：JHN 1:1 の θεός は述語主格候補。ただし「有冠詞側＝主語、無冠詞側＝述語」を普遍的な決定規則として実装しない。
3. **独立主格・懸垂主格**：登録例の統語関係と検出条件にずれがある。REV 1:4 の書簡差出人と ACT 7:40 のモーセ句は、構文境界・再開要素の再分析が必要。
4. **呼格との重複**：nominative.vocative_nominative と vocative.nominative_for_vocative は同じ現象を別カテゴリに二重登録している。
5. **不定詞文・感嘆文・表題句**：無動詞性だけでは構文を特定できない。ROM 7:24 は後続に定形動詞があるため、現行の no_finite 条件は代表例と不整合。

## 4. 暫定処置

- retain_redefined: subject, predicate_nominative, apposition, exclamation, title_nominative
- unresolved: nominative_absolute, pendens, vocative_nominative
- merge: indeclinable
- replace: subject_with_infinitive

## 5. 結論

主格10タイプのうち、通常の統語機能として残せる候補はある一方、独立主格・懸垂主格の代表例と検出条件には重要な再検討点がある。不変化語は主格機能の下位分類ではなく形態的性質として分離し、呼格転用は呼格側と統合する方向が妥当。処置案は暫定。

No production code, syntax registry, or StudyPanel behavior was changed.

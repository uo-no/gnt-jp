## 1. 方針

現行の分類名を独立体系として承認するものではない。代表例のコーパス形態・法・語順を確認し、概念の境界、用例の適合性、検出条件の妥当性を初回点検した。暫定処置はすべて再検証前提である。

このカテゴリは語ではなく従属標識（接続詞・関係代名詞）をアンカーとし、節全体の機能を分類する。対象範囲の取り方（節境界）が判定の前提になる点が、語レベルのカテゴリとの大きな違いである。

## 3. 初回に判明した問題

### 3.1 条件文4類は形態の類別であって、意味のラベルではない

第1〜第4類は Wallace の教育的な類別で、前件の形態（接続詞と法の組み合わせ）で決まる。第2類のように形態と意味（反事実）が強く結びつくものもあるが、第1類の「事実仮定」は話者が議論のために事実として扱うという語用の読みであり、εἰ＋直説法という形態からは従わない。独立体系では、4類は形態による類別として保持し、名称に含まれる意味の主張は読みの注釈に降ろすべきである。

また類別の網羅性にも限界がある。混合型の条件文（前件と帰結節で類が食い違うもの）、εἰ＋接続法の現在一般的条件などは、この4類では表現できない。類別は代表的な型の目録として扱う。

### 3.2 causal_hoti は残余クラスとして定義されている

内容節（substantival_hoti）は「直前にリスト内の導入動詞がある」ことで判定され、理由節（causal_hoti）は「そのリストに該当しない」ことで判定される。理由節であることの積極的な根拠は条件に含まれていない。

導入動詞リストは10語で、発話・認識を表す動詞の全体から見れば一部にすぎない。リストの拡張で境界が動く設計であり、理由節を独立タイプとして立てるかどうかは、積極的な判断基準（主節との意味関係など）を定義できるかにかかる。今回は unresolved として残す。これまで監査してきた「〜でないことによる判定」（主格の拡大コプラ型、与格の主体・手段など）と同じ構造の問題である。

なお、引用を導く ὅτι（recitativum）は内容節とも理由節とも別のはたらきだが、この2タイプでは区別されていない。節の機能を設計する際に併せて扱う。

### 3.3 ἵνα 節の機能は目的に限らない

purpose_hina は ἵνα＋接続法を目的節とするが、ἵνα 節には願望・命令・要求の内容を表す名詞的な用法（「〜するように」）も広くある。標識と法だけでは目的と内容を切り分けられず、導入する動詞と文脈を見る必要がある。タイプとしては、ἵνα 節という形式に機能の候補（目的／内容）を併記する形が実態に合う。

### 3.4 result_hoste の条件式の結合順序が曖昧

必須条件 `inf_or_ind` は `target_lemma_in(['ὥστε']) AND clause_has_infinitive() OR clause_has_mood('indicative')` と書かれている。AND と OR の結合順序の解釈によっては、「節内に直説法がある」という条件だけで（ὥστε がなくても）成立し得る。評価器がこの式をどう解釈するかは Pass C で実地に確認する必要がある。同種の表記は属格など他カテゴリの条件式にも見られるため、横断的な確認事項として記録する。

### 3.5 関係節は代名詞カテゴリと同じ先行詞条件を共有する

adjectival_relative は、代名詞監査で問題になった relative と同じ `has_antecedent()` を必須条件に使う。先行詞のない自由関係節（MRK 3:29 型）は、語レベルでも節レベルでも拾えない。役割分担としては、関係代名詞は語レベルの分類、関係節は節レベルの機能と、軸を明示すれば併記は正当である。ただし先行詞の有無は両軸に共通する下位区分として設計すべきであり、必須条件からは外すのが適切という所見は代名詞監査と共通である。

### 3.6 比較節の条件は弱い

comparative_kathos の必須条件は、標識レンマと「節内に定形動詞がある」ことだけであり、καθώς の時間的・理由的な用法との切り分けはできない。機能の確定は文脈依存であることを、タイプの側に明記すべきである。

## 4. 検出ロジックの初回所見

1. **節範囲の取り方が全判定の前提**：`clause_has_mood` などは節内トークンの走査に依存する。節境界の定義（句読点・節区切り）がずれると、法の判定も ἄν の帰属もずれる。Pass C では節境界の精度そのものが検証対象になる。
2. **形態ベースのタイプは安定**：条件文4類、時間節2タイプは標識＋法で再現性高く判定できる。節カテゴリの中では検出可能性の評価が高い群である。
3. **機能ベースのタイプは文脈依存**：ὅτι の内容／理由、ἵνα の目的／内容、καθώς の比較／その他は、標識だけでは決まらない。候補提示では確度の差として表れるべき領域である。

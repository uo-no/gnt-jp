## 1. 監査方針

不定詞であるという形態・法の情報と、不定詞句が文中で担う機能を分けて評価する。冠詞・前置詞との結び付きは構造的特徴、目的・結果・原因・時間・手段は意味関係、主語・補語・間接話法は構文上の役割として整理する。単一の共起語や語順だけで意味機能を確定しない。

## 3. 横断的な問題

1. **構造と意味機能の階層差**：冠詞付き不定詞は形態・構造上の特徴であり、目的・時間・原因などの意味機能や、主語・補語などの構文機能と同列に排他的分類しない方がよい。
2. **時間と手段の競合**：MAT 13:4 の ἐν τῷ σπείρειν は、同じ形式が時間・手段の候補になり得る。前置詞＋冠詞＋不定詞のパターンだけで手段を確定しない。
3. **補語・主語・間接話法の境界**：不定詞の主語、補語、発話内容は、同一節内の語彙共起ではなく、支配関係・項構造・意味上の主語・節の埋め込みを確認する。
4. **意味関係の判定**：目的・結果・原因は接続形式が候補抽出を助けるが、最終判断には主節との意味関係が必要。
5. **並列不定詞**：MAT 16:21 のように一つの非人称述語に複数の不定詞が並ぶ構文がある。検出単位を単語単位に固定せず、句・並列構造を扱う必要がある。
6. **例示とコーパス照合**：MAT 26:32 は章ファイルを取得できず、登録例の本文形態を独立照合できなかった。未確認を確認済みに数えない。

## 5. 結論

11タイプを点検し、10タイプは代表例の本文または登録された構造説明を評価できた。MAT 26:32 はコーパスファイル取得不能のため未照合。特に、冠詞付き不定詞を独立した意味機能として扱わないこと、ἐν τῷ＋不定詞の時間・手段を形式だけで決めないこと、主語・補語・間接話法の識別に項構造を必要とすることが重要である。

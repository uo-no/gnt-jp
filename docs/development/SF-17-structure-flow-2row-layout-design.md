# SF-17-A Structure Flow 2段レイアウト再設計（design only・コード変更なし）

作成: 2026-08-12
State: DESIGN AUDIT（実装しない）
前提: [SF-14](./SF-14-frame-connector-implementation-structure.md), [SF-16](./SF-16-structure-flow-layout-implementation.md)
確定事項（SF-16まで）: Word Order が語順担当／Structure Flow は原文順を表示目的にしない／4チャネル分離（包含/frame/referent/role）／frame は Lowfat 明示 node-id のみ／推論禁止／ὃ→πᾶン非表示／mobile 縮退可／横「→」撤去可。

> 中心の問い: **横軸を何にするかではなく、「上段・下段の空間配置で構造関係をどれだけ直感的に理解できるか」。**
> 目的は文法解析図ではなく「今見ている語の構造上の位置づけ」を読む UI。

## 0. 実データ（6:37/38/39/51・実測 role/frame）

- 6:37 δίδωσίν(v)  frame: →〜するもの(o) / →私(io) / →父(s)。band sibs role: 目的語/動詞★/間接目的語/主語
- 6:37 ὃ(o)        与える(v) の項。ὃ↔与える のみ。ὃ→πᾶν は無し
- 6:37 πᾶν(role無・親np=主語) frame無
- 6:38 御心(role無) frame無
- 6:39 この(p=補語) frame無。referent 同文: この→滅ぼす/立ち上がる（大 chip 内）
- 6:51 〜である(vc) frame無。band: 主語 私 / 繋ぎ★ / 補語 …天下る

## 1. 現在（SF-16）: 横一列 layout rank

```
所属するまとまり
 主語    動詞★    目的語     間接目的語
[父]   [与える]  [〜するもの]   [私]
        ╰─弧(下・実線・▸)→父/〜するもの/私─╯
上位 [ …節… ]（縦線＝包含）
```
問題: 主語・動詞（核）と項（目的語/間接）が同じ1行に混在し、「誰が・何をする／何を・誰に」の階層が空間から読めない。frame 弧が全て下側に集まる。

## 2. 新レイアウト3案（ASCII・実データ）

### 案A: 上段＝主語＋動詞、下段＝項（2段・推奨候補）
上段＝役割 {s, v, vc}（核）。下段＝{o, io, p, adv…}（項）。frame 線は上段述語→下段項（短い縦エルボ・▸）。
```
■ 6:37 δίδωσίν(focus=動詞)
 所属するまとまり
   主語        動詞★
  [父]        [与える]
                └┬─────────┐        （frame: 与える→項。父=A0は上段配置で表現し線は引かない）
              目的語     間接目的語
             [〜するもの]▸   [私]▸

■ 6:37 ὃ(focus=目的語)
   主語        動詞
  [父]        [与える]
                └───▸ 目的語★
                     [〜するもの]        （ὃ↔与える のみ。ὃ→πᾶν 描かない）

■ 6:37 πᾶン(role無) … 2段化できない → 単段(中立順)へ縮退
 所属するまとまり · 主語   [すべての]★  [〜するもの与える私父]

■ 6:38 御心(role無) … 単段   [御心]★ [［冠詞］私の]

■ 6:39 この(補語, referent)
   主語              繋ぎの動詞
  [御心…送る私]      [〜である]
   補語★            目的語
  [この]            [ …最後の日 ]
   ⋯⋯⋯▸(点線referent)→ 滅ぼす / 立ち上がる   （大 chip 折返し時は注記へ縮退）

■ 6:51 〜である(focus=繋ぎの動詞)
   主語        繋ぎの動詞★
  [私]        [〜である]
   補語
  [ …天下る ]
```

### 案B: focus 中心の上下配置（radial）
focus を中央、主語を上・項を下へ。
```
        主語
       [父]
         │
      [与える]★           ← focus 中央
      ┌──┴──┐
   目的語  間接目的語
  [〜するもの] [私]
```
- 空間対応は強いが、**上下が包含チャネルと最も紛らわしい**、項3つ以上で放射崩れ、mobile の2D縮退が難しい、grammar-tool 感最大。focus=項時は上に述語。

### 案C: 主語→動詞を上段スパイン、項を動詞から分岐
```
 主語 ── 動詞★
[父]    [与える]
          ├─▸ 目的語 [〜するもの]
          └─▸ 間接目的語 [私]
```
- 動詞から項が枝分かれ（tree 的）。frame 明示・短い。ただし枝リストが**構文木に見えやすい**（grammar-tool 感やや高）。項が縦に伸びるため縦長。

## 4. 推奨 ＝ 案A（上段＝主語＋動詞 / 下段＝項）

**中心の問いへの回答**: 上段＝「誰が・何をする（主語＋動詞）」、下段＝「何を・誰に（項）」という**2段の意味的階層**が、構造関係を最も直感的に読ませる。frame 線は上段述語→下段項の**1段差の短い縦エルボ**で、「動詞がその項に届いている」ことが一目で分かる。主語(A0)は**上段配置**で表し線を引かない＝線が最小・交差最小。案B は包含チャネル（上下）と衝突、案C は構文木化のリスクが案Aより高い。

## 5. レイアウトルール（案A）

- **上段 role**: `{s:主語, v:動詞, vc:繋ぎの動詞}`（節の核）。**下段 role**: `{o:目的語, io:間接目的語, p:補語, adv:副詞的, aux…}`（項）。各段内は SF-16 の layout rank 順。
- **role→段** は role のみで決める（SF-16 の日本語対応を流用。p→補語）。**role 無しは段を作らず単段（中立順・focus 先頭）**。role 推測付与は禁止。
- **frame 線**: focus-incident・同 band・明示 node-id・非ゼロ・実在のみ。上段述語(v/vc)→下段項へ実線＋▸。**主語(上段)への A0 線は引かない**（上段配置で表現）。focus が項なら その項↔述語の1本のみ。**ὃ→πᾶン は描かない**。
- **containment**: 帯＋上位への縦線（左端・矢頭なし）。frame の縦エルボと**位置（左端 vs 中央）・矢頭有無**で区別。frame を包含線に見せない。
- **referent**: 同文明示のみ・点線。大 chip 折返し時は注記へ縮退。
- **role キャップ**: 各 chip 直上（上段/下段とも）。
- **mobile/折返し**: 2段維持できれば維持、破綻時は単段＋注記（SF-14/16 縮退）。

## 6. SF-16 から：維持 / 変更

**維持**: 4チャネル分離とその意味；frame は Lowfat 明示 node-id のみ・推論禁止・ὃ→πᾶン非描画・文外/ゼロ非接続；role の帰属を偽らない（role 無しに付与しない・unit 由来は帯見出し）；role→日本語（p→補語）；layout rank（各段内の順に流用）；横「→」なし；mobile 縮退；focus 強調；包含（帯＋上位）。

**変更**: 単段横一列 → **2段（上段核 s/v/vc・下段項 o/io/p/adv）**；frame 弧（同段の下）→ **上段→下段の縦エルボ短線（▸）**；role が段（上/下）配置も決める；主語 A0 は線でなく上段配置で表現。

## 7. 実装時の難所（実装フェーズ SF-18 で対処）

1. **frame 線の縦接続**: 上段 chip 下端→下段 chip 上端を SVG 実測で結ぶ（SF-14 の測定機構を縦方向へ拡張）。role キャップ（下段 chip 直上）と線が重ならない配線。
2. **containment との非混同**: 包含縦線（左端）と frame 縦エルボ（中央・▸）の空間/様式分離を担保。
3. **2段の折返し判定**: 上段/下段それぞれが折返す条件、および 2段自体を崩して単段＋注記へ落とす閾値。
4. **段割りと focus**: focus が下段（項）の時に上段（述語）を近接表示、focus が上段の時に項を下段に。role 無し band は単段。
5. **巨大 chip（6:39/6:51 の節丸ごと）**: 下段が巨大 → 折返し→縮退。referent も注記へ。
6. **data 属性/index の再設計**: 段をまたぐ frame 線のため、chip に段情報＋index を持たせ、enhancer が段間を結ぶ。
7. **role 無し・部分 role band**: 上段に置ける role が無い場合の単段フォールバック規則。

## 8. 結論

推奨は **案A（上段＝主語＋動詞 / 下段＝項、frame は上段→下段の短い縦エルボ）**。
本 SF-17-A はコードを変更しない。承認後に実装フェーズ（SF-18）へ進む。

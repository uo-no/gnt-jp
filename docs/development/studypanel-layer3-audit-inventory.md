## What this inventory measures

This is a **traceability baseline**, not a claim that every type named in the log has passed a complete audit. It records whether each type ID is explicitly mentioned in the current Layer 3 semantic-information audit log. Some entries were examined individually; others appear as part of a bulk scan. A name appearing in the log is therefore not, by itself, proof of full completion.

- **記録あり（個別監査・一括走査を含む）:** 39 types are explicitly named in the current semantic audit log.
- **この監査記録ではタイプ別記録を未確認:** 203 types are not explicitly named in that log. This does **not** mean no earlier work exists; it means this specific audit log does not yet provide traceable type-level evidence.

The taxonomy-label audit is a separate dimension: PR #221 reports review of all 242 Japanese syntax labels, with 124 descriptions updated, 116 retained, and 2 awaiting source verification. That work must not be conflated with this Layer 3 audit of evidence, interpretation strength, competing readings, and reading-impact explanations.

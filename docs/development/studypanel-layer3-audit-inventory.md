## What this inventory measures

This is a **traceability and triage baseline**, not a claim that a type is fully complete merely because it appears in a section. Classification is based on the type-specific semantic/evidence sections §§14.24–14.46, not on earlier technical work such as signal wiring, gate coverage, browser/UI audits, or the older taxonomy-label audit.

- **個別焦点の監査記録あり:** 18 types are explicitly examined in a focused semantic/evidence entry. This does not imply every field or every interpretation issue is fully closed.
- **一括走査のみ:** 12 types appear in the bulk scans (§§14.37–14.40) but have no separate focused semantic/evidence entry in §§14.24–14.46.
- **タイプ別意味監査記録なし:** 212 types have no explicit type-level semantic/evidence record in §§14.24–14.46. Some may have substantial prior technical or taxonomy work; that work is a separate dimension and is not silently counted as semantic audit completion.

The earlier taxonomy-label audit is separate: PR #221 reviewed all 242 Japanese syntax labels, updating 124 descriptions, retaining 116, and leaving 2 awaiting source verification. Those numbers are not added to this Layer 3 semantic/evidence audit count.

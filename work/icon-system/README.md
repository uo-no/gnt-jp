# Bible App アイコンシステム仕様書

Version: 1.0  
Status: Design specification draft  
Scope: 共通アイコンと3シリーズカラー

## 1. 基本方針

- マスターは白背景・黒線の開いた本アイコン。
- 3シリーズは同一のSVGパス・同一の比率を使用し、背景色のみ変更する。
- 十字架、文字、枠線、追加装飾は入れない。
- シックで落ち着いた印象を優先し、過度なグラデーションや立体表現は避ける。
- アイコン形状の変更は、全シリーズへ同時に適用する。

## 2. シリーズと色

| シリーズ | 用途 | 背景色 | アイコン |
|---|---|---|---|
| 青 | 教父文書 | `#1E3A6D` | 白 |
| 赤 | 旧約聖書 | `#7A1F2A` | 白 |
| 緑 | 新約聖書 | `#173B2D` | 白 |

各色は深みのある落ち着いた色調とする。配色はアイコンの背景色として使用し、3シリーズ間で役割を入れ替えない。

## 3. マスターアイコン

- アートボード: 1024 × 1024 px、正方形
- マスター背景: 白 `#FFFFFF`
- マスター線色: 黒 `#000000`
- モチーフ: 開いた本、中央の縦線、下部の曲線3本
- 角丸背景を含める場合の参考半径: 170 px（アートボード比 約17%）
- 配置: 正方形の視覚的中央
- 余白: アイコン外周に約15–20%を目安に確保
- 線端・接合部: 丸みを保ち、線の太さを全体で統一

**重要:** マスターの形状を確定した後は、色違いを個別に描き直さず、同一のSVGパスから生成する。

## 4. 形状ルール

1. 左右のページ輪郭を共通形状として維持する。
2. 中央の縦線を残し、ページの境界を明確にする。
3. 下部の曲線は3本を維持する。
4. 中央の接合部が縮小時に黒くつぶれないようにする。
5. 曲線間の白い隙間を均一に見せる。
6. 左右の重心・傾き・余白を整える。装飾的な線や文字は追加しない。

## 5. 使用先

- iOS / Android アプリアイコン
- Webサイトのファビコン
- ブックマーク・ホーム画面ショートカット
- シリーズ紹介や関連アプリ一覧

使用先ごとに必要なサイズへ書き出す。小サイズでは中央線と3本の曲線の識別性を確認する。プラットフォーム固有の角丸マスクを考慮し、元データに角丸を二重適用しない。

## 6. バリエーション

基本運用は3色のシリーズ版とする。モノクロ、反転、アウトライン版は補助用途に限り、主要なアプリ表示ではシリーズカラーを優先する。

## 7. 品質チェック

- [ ] 3色版が同一の形状・比率である
- [ ] 中央線が見える
- [ ] 下部の曲線が3本と認識できる
- [ ] 1024 px、192 px、48 px、32 pxで視認性を確認した
- [ ] iOS / Androidのマスク後も端が切れない
- [ ] 白背景・黒線のマスターを保管している
- [ ] 背景色以外の差分がない

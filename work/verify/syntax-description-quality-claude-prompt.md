# Claude作業指示：統語ラベル説明242件の独立品質評価

まず `work/verify/syntax-description-quality-all-proposals.md` を読み、全242件の現行説明とChatGPT初稿を独立に評価してください。これは文章校正だけでなく、ギリシャ語文法の正確性と分類体系の整合性を問う監査です。

## 禁止事項
- ChatGPT案を前提として追認しない。
- Wallaceの本文を実際に確認していないのに、確認済み・原典にそう書いてあると主張しない。
- もっともらしさだけでGreek grammar claimsを補わない。
- 242件の一部だけを評価して全件完了と報告しない。
- `syntax-registry.json` をこの評価フェーズで変更しない。

## 作業
1. 242件すべてをID単位で評価し、正確性・明瞭さ・近接型との区別・断定の強さ・原典確認の必要性を判定。
2. 各項目を「採用」「要修正」「要原典確認」に分類。要修正は必ず代替文を提示。
3. 重大な誤りの可能性があるものを最初にまとめ、次に全件の評価表を出す。
4. 以下を横断監査する：主語的/目的語的/複合属格、材料/内容/説明的同格属格、属格/与格の時間用法、冠詞用法、分詞用法、節分類と接続詞分類の二層構造、γάρ/δέ/οὖν等の接続詞・談話ラベルの重複、前置詞の格支配、談話機能を語順だけで推定する型。
5. Wallace参照ページが示されている項目は、アクセスできる場合のみ該当箇所を照合し、照合できない項目は「未照合」と明示。
6. 全件レビュー結果を `work/verify/syntax-description-quality-claude-review.md` に書き出すための内容を作成。まずはレポート案を返し、実装担当者がファイル作成できるようにする。

## 出力形式
各IDにつき：`ID | 判定 | 問題点 | 推奨説明文 | 根拠/要確認事項`。説明文は読者向けの短い日本語とし、判定ヒントや実装メモを混在させない。原典未確認は正直に明示する。

最後に、全242件の件数集計、重大な修正候補、横断的な用語統一案、レジストリ更新前に必要な確認を列挙してください。

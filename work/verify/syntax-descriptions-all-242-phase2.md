# 統語説明文・第2段階監査：属格・与格・分詞の優先確認

対象レジストリ：`fix/syntax-description-ja-update` の `public/assets/data/syntax-registry.json`。
この段階では、実際の本文・原典を照合せずに説明文を直接書き換えることはしない。以下は説明文の内部整合性と、候補比較時に読者が区別できるかを確認した結果。確定的な文法判断ではなく、次に原典・実例で検証するレビュー項目である。

## 1. 属格：隣接候補の区別

| 組み合わせ | 現行説明の状態 | 監査結果・次に必要な確認 |
|---|---|---|
| 主語的属格 / 目的語的属格 | 両者とも動作名詞を動詞に言い換えたときの役割として説明されている | **比較表示に適する**。同じ属格句を動詞文に言い換え、「属格が行為者か、行為の対象か」を対照させる。文脈だけで決まらない例では両候補を残す。 |
| 所有属格 / 関係属格 | 所有・帰属と、親族・師弟関係という定義 | **部分的に重なる**。関係属格を所有属格の単なる言い換えにしないよう、関係を表す名詞（息子・弟子など）を含む本文例で境界を確認する。 |
| 描写的属格 / 属性属格 | 両者とも中心名詞の性質・特徴を説明する定義 | **区別が不明瞭になりやすい**。Wallaceの分類上の違いと各実例を照合し、UI上で別候補として同時提示する必要があるか確認する。名前だけから差を創作しない。 |
| 説明的同格属格 / 内容属格 | 「内容を具体的に説明」と「内容を示す」が接近している | **要原典照合**。属格が中心名詞の内容を言い換えるのか、容器・集合等の内容を示すのか、例文で区別できるか確認する。 |
| 材料属格 / 内容属格 | 物の材料・構成要素と、名詞が表す内容という定義 | **例の再確認が必要**。物質・内容・商品の関係を同一視しない。黙示的な名詞関係を文脈に即して確認する。 |
| 手段属格 / 起源属格 / 分離属格 | 手段、由来、離れる対象として説明 | **比較表示に適するが、動詞・名詞との関係が必要**。「何によって」「どこから生じ／離れるか」を実例で示し、格形だけで決めない。 |
| 時間属格 / 時間与格 | 時間の種類・時間内と時点の対比が説明されている | **対照の骨格は有用**。例文がその違いを実際に示すか、例示された訳が不自然でないかを原典とコーパスで確認する。 |
| 属性属格 / 被属性属格（逆転） | 通常の属性関係と逆向きという説明。被属性属格の例示は未確認と明記 | **保留維持**。未確認例を確定例として表示しない。説明を確定する前に原典の該当節と本文を照合する。 |

## 2. 与格：隣接候補の区別

| 組み合わせ | 監査結果・次に必要な確認 |
|---|---|
| 利益与格 / 不利益与格 | 意味の方向は対照的。実際の受益者・不利益を受ける側を本文から説明できるか確認する。否定的な語だけを根拠に判定しない。 |
| 手段与格 / 様態与格 | 「何を使って」対「どのように」という読者向けの対比は可能。ただし具体例がその区別を支えるか確認する。 |
| 領域与格 / 基準与格 | 「どの領域で成り立つか」対「どの観点について述べるか」の対比を提案。両者が重なる例では断定しない。 |
| 時間与格 / 時間属格 | 与格は時点、属格は時間の種類・その時間内という説明を候補比較に利用できる。ただし傾向を絶対的な規則として表現しない。 |
| 動詞支配与格 / 間接目的語与格 | 格だけで役割を判定せず、動詞が与格を直接目的語として要求するか、受け手を表すかを動詞の語法と構文から確認する。 |
| 行為者与格 / 手段与格 | 行為者（誰が行うか）と手段（何によって行うか）を区別する。受動構文・完了形などの条件を本文で検証する。 |

## 3. 分詞：同じ形からの複数解釈

| 組み合わせ | 監査結果・次に必要な確認 |
|---|---|
| 形容詞用法 / 実体用法 | 名詞を限定・説明しているのか、「〜する人／もの」として名詞相当に使われるのかを、冠詞の有無だけでなく構文から確認する。 |
| 述語的分詞 / 迂言的分詞 | 分詞が主語について述べる述語なのか、εἰμί等と一体の動詞表現を構成するのかを、時制・相・構文全体から判定する。 |
| 時間 / 理由 / 様態 / 手段 / 条件 / 譲歩 | 形式だけで候補を決めず、主動詞との意味関係を日本語の言い換えで対照する。候補比較では「〜したとき」「〜なので」「〜しながら／〜して」「〜することによって」「もし〜なら」「〜にもかかわらず」を具体的に示す。 |
| 付帯状況 / 手段 / 様態 | 訳し分けが似る場合があるため、単に日本語訳を並べず、主動詞との関係が「別の付随動作」「手段」「動作のあり方」のどれかを説明する。 |
| 目的 / 結果 | 「何のために行ったか」と「その結果どうなったか」を分ける。未来分詞等は手掛かりだが、形だけで結論にしない。 |
| 属格絶対 / 通常の副詞的分詞 | 属格名詞・分詞のまとまりが主節と別の主語を持つ構文を作っているかを確認する。時間・理由等の意味分類とは別の軸として扱う。 |
| 補語用法 / 間接話法分詞 | 前者は動詞の意味を完成させる補い、後者は知覚・認識の内容を表す。動詞の語法と構文を根拠に区別する。 |

## 4. 現段階での修正判断

- **説明文を一括自動改稿しない。** 242型の説明をラベル名だけから生成すると、分類体系の区別を誤って作り出す危険がある。
- 上記は候補比較を設計するためのレビュー項目であり、すべての組み合わせを本文に表示するという意味ではない。実解析で同じ語句に複数候補が出た場合だけ、文脈に合う比較を提示する。
- 「根拠を詳しく見る」は、実際の箇所に存在する形態・構文・語法・文脈上の手掛かりを示せる場合のみ使う。レジストリに書かれた一般的な判定シグナルを、その箇所で確認済みの根拠として見せない。
- 次段階は、各分類の原典該当ページと代表例を照合し、上表の「要確認」を採用・修正・保留に分けて記録する。特に ROM 6:4 の被属性属格の例示は、検証完了まで保留する。

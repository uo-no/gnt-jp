# 統語ラベル説明242件・原典照合メモ（第4回）

- 対象: `public/assets/data/syntax-registry.json`（main）および統合候補 v2
- 状態: **監査メモのみ。レジストリ・アプリコード・統合候補v2は変更していない。**
- 今回の焦点: 属格の時間用法、被属性属格と属性属格の混同、時間与格と時間属格の対比。

## 1. `genitive.time` — 基本定義は原典に支持される

Wallace, *The Basics of New Testament Syntax*, §19「Genitive of Time」では、単純属格の時間用法を「時間の種類」または「その時間内に起こること」として説明し、例にヨハネ3:2 `νυκτός`（夜の間に）とルカ18:12 `δὶς τοῦ σαββάτου`（週に二度）を挙げている。

したがって、第二監査候補の「出来事が起こる時間の種類、またはその出来事が起こる時間内を示す」は妥当。現行の「『いつのあいだに』ではなくどの種類の時」とする対比は、原典が「kind of time」と「time within which/during which」の両方を認めることを十分に表せないため、修正候補を優先する。

**推奨候補**
> 出来事が起こる時間の種類、またはその出来事が起こる時間内を示す用法（例：「夜に」「週に二度」）。時間与格が特定の時点を示す傾向があるのに対し、時間属格は時間の種類や、その時間内で起きることに焦点がある。具体的な解釈は文脈で判断する。

ただし、前置詞 `ἐκ` や `ἀπό` と共に使われる時間表現は、単純な時間属格とは意味が異なることがある。前置詞句をこの用法に一括分類しない。

## 2. `dative.time` — 「時点」の説明は妥当

同じWallaceの説明では、時間を示す3つの格の意味上の傾向を、属格＝時間の種類／その時間内、与格＝時点（「いつ」）、対格＝時間の長さとして対比している。

したがって、第二監査候補の「出来事が起こる時点・時刻を示す」は原典の説明に沿う。もっとも、これは文脈を無視した機械的な一対一対応ではなく、一般的な傾向として表現するのが安全。

**推奨候補**
> 出来事が起こる時点・時刻を示す用法（例：「その日に」「その時に」）。時間属格が時間の種類や、その時間内を示す傾向があるのに対し、時間与格は「いつ起きたか」という時点を示す傾向がある。具体的な解釈は文脈で判断する。

## 3. `genitive.attributive` と `genitive.attributed` — 例の混同を確定的に避ける

Wallaceの公開テキストには、図表項目として「属性属格と被属性属格の意味関係」が独立して掲載されている（図9）。`σῶμα τῆς ἁμαρτίας`（Rom 6:6）は、同書の属性属格の説明に関連づけられる例であり、少なくともこの表現を `genitive.attributed` の典型例としてそのまま使うことは避けるべきである。

公開された二次資料にも分類のばらつきがあるため、この監査では `σῶμα τῆς ἁμαρτίας` の最終的な意味分類そのものを独自に確定しない。安全に言えるのは、**統合候補の `genitive.attributed` にこの例を肯定例として再掲しない**という点である。

### 推奨する処置

- `genitive.attributive`: 「属格が中心名詞の性質・特徴を表し、形容詞的に言い換えられる」という説明を核にする。
- 「ヘブライ語的」は定義そのものにせず、必要なら別の補足情報として扱う。
- `genitive.attributed`: 例を削除し、「中心名詞が属格名詞の性質を表すように理解される、属性属格とは意味関係が逆向きの用法」と定義する。実例はWallace原典の当該項目を直接確認するまで追加しない。
- レジストリにある `example_verse: ROM 6:4` は、この監査だけでは当該用法の実例だと確認できていない。自動的に承認せず、原典の例示・本文の両方を照合する。

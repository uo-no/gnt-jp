## 原典確認・保留項目

- `genitive.attributed`: 定義と ROM 6:4 の例示は未確定。`σῶμα τῆς ἁμαρτίας`（ROM 6:6）を典型例として再掲しない。
- `genitive.attributive`: 「ヘブライ語的用法」の扱い。
- `article.granville_sharp` / `article.colwell`: 原典照合により、断定的な説明を避ける候補文に修正。検出器の意味判定限界は別タスク。
- `particle.emphasis_per` / `particle.emphasis_toi`: 単独形 περ・τοι はSBLGNT新約本文に該当例がなく、複合語中の形とは区別する。現行説明は将来の本文・異読データを想定した保留項目として維持。
- `genitive.time` / `dative.time`: 公開されている Wallace 要約版は「時間属格＝時間の種類／その時間内」「時間与格＝時点」という区別を支持するが、個別用例を格だけで機械判定しない。
- `preposition.improper` および固有前置詞の格別ラベル: 対象語リスト・格支配・原典の定義を最終確認。

- `particle.attention_de` — **採用候補**: δή が、命令や勧奨の表現とともに、聞き手の注意を促す働きをする用法。具体的な訳し方は文脈に応じて判断する。
- `particle.emphasis_per` — **原典確認待ち（新約本文に単独形の該当例なし）**: περ が強意を加える小辞。単独形はSBLGNT新約本文に現れず、εἴπερ・καθάπερ など複合語中の文字列とは区別する。現行検出が新約本文で発火しないことは、検出バグを意味しない。
- `particle.emphasis_toi` — **原典確認待ち（新約本文に単独形の該当例なし）**: τοι が強意などを加える小辞。単独形はSBLGNT新約本文に現れず、μέντοι など複合語中の文字列とは区別する。現行検出が新約本文で発火しないことは、検出バグを意味しない。

### 名詞句

- `nominal_syntax.simple_np` — **採用候補**: 冠詞や修飾語を伴わない、中心となる名詞だけの名詞句。
- `nominal_syntax.articular_np` — **採用候補**: 冠詞を伴う名詞句。冠詞は指示対象を特定したり、文脈上既知のものとして示したりすることがあるが、有冠詞だから必ず特定とは限らない。
- `nominal_syntax.anarthrous_np` — **採用候補**: 冠詞を伴わない名詞句。無冠詞であることだけから、不特定・質的など特定の意味を決めることはできない。
- `nominal_syntax.modified_np` — **採用候補**: 形容詞・属格・分詞・前置詞句など、少なくとも一つの修飾語を伴う名詞句。
- `nominal_syntax.multiple_modifier_np` — **採用候補**: 形容詞・属格・分詞・前置詞句など、複数の修飾語を伴う名詞句。
- `nominal_syntax.appositional_np` — **採用候補**: 二つ以上の名詞句が同じ人・物を指し、後の表現が前の表現を言い換えたり補足したりする同格構造。
- `nominal_syntax.substantival_phrase` — **採用候補**: 冠詞と形容詞・分詞・前置詞句などが組み合わさり、明示された名詞なしで名詞句として働く構造。
- `nominal_syntax.head_initial_np` — **採用候補**: 名詞句の中心となる名詞が、冠詞を除いて句の先頭に置かれ、その後に修飾語が続く語順。
- `nominal_syntax.head_final_np` — **採用候補**: 修飾語が中心となる名詞より前に置かれ、名詞が句の後ろに来る語順。語順の型だけで修飾関係を決めず、句全体を確認する。
- `nominal_syntax.nested_np` — **採用候補**: 一つの名詞句の内部に、別の名詞句が含まれる入れ子構造。
- `nominal_syntax.complex_np` — **採用候補**: 属格の連鎖などにより、名詞句の内部に複数段階の修飾関係が重なる構造。
- `nominal_syntax.vocative_np` — **採用候補**: 呼格を中心にした名詞句。相手への呼びかけとして用いられる。

### 談話構造

- `discourse.topic_fronting` — **採用候補**: 節の前方に置かれ、何について述べるか（主題）を示すと解釈される表現。節頭にあることだけで主題と断定せず、文脈を確認する。
- `discourse.focus_fronting` — **採用候補**: 節の前方に置かれ、特に注目させたい情報（焦点）を示すと解釈される表現。語順だけで焦点と断定せず、対比や文脈を確認する。
- `discourse.emphasis_word_order` — **採用候補**: 通常とは異なる語順によって、ある語句に強調や対比が生じる可能性を示す用法。何が強調されるかは文脈を含めて判断する。
- `discourse.left_dislocation` — **採用候補**: 文の本体から少し独立した位置に先行表現を置き、後の節で代名詞などを使ってその内容を受け直す構造。
- `discourse.right_dislocation` — **採用候補**: 文の後方に置かれた表現が、先行する代名詞などの指示内容を具体的に言い直すと解釈される構造。判定には語順と文脈の確認が必要。
- `discourse.parenthetical` — **採用候補**: 発話・思考を表す動詞などが文の途中に挿入され、話し手の補足やコメントを加える用法。
- `discourse.explanatory_parenthesis` — **採用候補**: ὅ ἐστιν・τοῦτ᾽ ἔστιν などを用い、直前の語句を言い換えたり説明したりする挿入表現。
- `discourse.contrast_men_de` — **採用候補**: μέν…δέ が、文や節をまたいで二つの内容を対比する談話上の構造。接続詞としての分類と重なる場合がある。
- `discourse.backgrounding` — **採用候補**: 主筋となる出来事に対し、従属節や分詞などが背景・状況情報を加えると解釈される用法。動詞形だけで背景化を決めず、談話の流れを確認する。
- `discourse.foregrounding` — **採用候補**: 物語や議論の主な展開を前に進める情報を示す用法。主節や歴史的現在は手掛かりになるが、前景化は文脈に基づいて判断する。

- `article.colwell`: 説明文を修正候補へ移動。検出器は冠詞側の名詞が主語であることや述語の定性を意味論的に確定していないため、説明文にその断定を残さない。

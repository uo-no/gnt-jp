# 第8段階：冠詞・不定詞・対格の優先監査

## 資料の方針

主資料は Wallace, *Greek Grammar Beyond the Basics* と *The Basics of New Testament Syntax*。Wallaceは新約本文の統語・釈義を結びつけ、各分類の定義と用例を検討する書物として刊行されている。公開されている *The Basics of New Testament Syntax* の不定詞章では、目的・結果・時間・原因・手段の各用法を別々に扱う。Smythはこの段階の分類根拠には用いない。

出典：
- Wallace, *Greek Grammar Beyond the Basics*, publisher overview: https://zondervanacademic.com/products/greek-grammar-beyond-the-basics
- Wallace, *The Basics of New Testament Syntax*, PDF: https://www.obinfonet.ro/docs/gk/resgk/wallace-basic-nt-greek.pdf

## 1. 冠詞の用法（11型）

### 現行記述で維持できる点

総称的用法、前出指示、後方照応、指示的用法などを、冠詞の意味・談話上の働きとして説明する方向は妥当。ただし、冠詞があることだけで「特定」「既知」「唯一」と断定しない注意は全型に一貫して適用する。

### 優先して修正・検証すべき型

| 型 | 監査所見 | 次の対応 |
|---|---|---|
| `article.monadic` 単一体的用法 | 「宇宙的・唯一的な実体」は専門的で、太陽・世界などの例を先に示した方が読みやすい。「唯一だから冠詞が付く」と一方向の規則にしない。 | Wallaceの定義と例を照合し、「その文脈で一つしかないものとして扱われる対象」といった説明が適切か確認。 |
| `article.well_known` 著名用法 | 「共同体に周知」は誰の共同体かが曖昧。共有知識・聖書的文脈・社会的に知られた対象のどれか、Wallaceの用法に沿って限定する必要。 | 代表例と単純識別・卓越的用法の境界を照合。 |
| `article.par_excellence` 卓越的用法 | 「ある類の中で最も著名」と「著名用法」が近い。型名だけでは区別が伝わらない。 | Wallaceの定義・例を比較し、区別が読者向けに成立するか検証。 |
| `article.abstract` 抽象名詞用法 | 「抽象名詞に付く冠詞」だけだと、単なる名詞の種類と冠詞の機能が混同される。 | 抽象概念を個別化・特定する用法なのか、分類上の意味を明示。 |
| `article.granville_sharp` グランビル・シャープ構文 | 現行説明に「単数の人称名詞」「καί」「一つの冠詞」などの条件があるのは重要。単純な冠詞配置だけで同一指示を断定しない注意も維持する。 | Wallaceの条件・除外条件・本文例を照合し、条件を短縮しすぎない。 |
| `article.colwell` コルウェル構文 | 現行ラベル「主語標識」は誤解を招き得る。コルウェルの観察は、無冠詞述語主格の語順と定性に関する傾向であり、単純に「主語を特定する規則」として扱えない。 | ラベルを「コルウェルの観察（無冠詞述語主格）」等に改める候補を検討。Wallaceの修正・限定を確認するまで断定的な規則として表示しない。 |

## 2. 不定詞の用法（11型）

### 比較表示の有用性が高い組み合わせ

| 組み合わせ | 読者向けの区別 | 実装時の注意 |
|---|---|---|
| 目的 / 結果 | 何を目指して行うか / その行為から何が生じるか | 接続表現・動詞の意味・文脈を合わせて判断。形だけで断定しない。 |
| 時間 / 手段 | いつ行うか / 何によって実現するか | `ἐν τῷ + 不定詞` は時間・手段の両方に関係し得るため、形だけで決めない。 |
| 補語 / 間接話法 | 動詞の意味を完成させる / 発話・思考の内容を表す | 動詞の語彙的な支配関係と、発話・認識内容の構造を区別する。 |
| 主語 / 補語 | 文の主語に相当する / 先行する動詞・形容詞等を補う | 非人称表現や補語を取る動詞の構文を確認。 |
| 冠詞付き不定詞 / 意味用法 | 句の形・名詞化という構造 / 目的・時間などの意味関係 | 同一階層の排他的候補として扱わない。冠詞付き不定詞は形の分類と意味の分類が重なり得る。 |

### 現行説明で要修正の候補

- `infinitive.complementary` の「補助動詞の思想を完結」「valency 辞書で判定」は日本語が不自然で、読者向け説明として不適切。「先行する動詞の意味を補い、何をしたい／できる／始めるのかを表す」などの平易な案を検討し、Wallaceの範囲と一致するか確認する。
- `infinitive.means` の「稀用法」は、頻度の根拠と対象コーパスを明示できる場合だけ使う。説明の中心は、時間用法との区別と本文上の根拠に置く。
- `infinitive.imperatival` は例としてローマ12:15の `χαίρειν`・`κλαίειν` を挙げているが、当該箇所の分類と採用版の例示をWallaceで照合するまでは、説明文に確定例として埋め込まない。
- `infinitive.articular` は構造分類（冠詞＋不定詞）であり、主語・目的語・時間・目的などの機能分類と重なる。候補比較UIで別軸として扱う必要がある。

## 3. 対格の用法（7型）

### 隣接候補の主な区別

- **直接目的語 / 不定詞の主語**：主動詞の目的語なのか、不定詞が表す動作の意味上の主語なのかを、どの動詞・節に係るかで区別する。
- **二重対格（人・物） / 目的語・補語**：二つの対格が二つの対象を表すのか、後の対格が目的語について何であるかを述べるのかを区別する。
- **同族対格 / 直接目的語**：動詞と同根の名詞が動作内容を重ねて表すのか、独立した対象を表すのかを確認する。
- **述語対格 / 不定詞の主語**：不定詞構文の内部で、どちらが意味上の主語で、どちらが述語なのかを構文全体から確認する。
- **副詞的対格 / 直接目的語**：動作の対象なのか、時間・程度・様態・観点などを加える副詞的要素なのかを区別する。

### 説明の具体性

`accusative.direct_object` の「他動詞の動作の直接の受け手」は「受け手」が間接目的語のように誤解されるおそれがある。「動詞の動作が直接及ぶ対象」とした方が、間接目的語との対比が明確になる可能性がある。Wallaceの定義と例を照合して確定する。

## 4. 全体の表示原則

1. Wallaceの用語と区別を先に確認し、その後に自然な日本語へ言い換える。語源・ラベル名から独自に分類の違いを作らない。
2. 構造分類（冠詞付き不定詞、コルウェル構文など）と意味・機能分類（目的、時間、主語など）を同じ軸の二択として扱わない。
3. `alternatives` は関連型の候補であり、同一トークンで実際に同時検出された証拠ではない。
4. 「頻繁」「稀」「典型的」「最も明確」などの頻度・強度表現は、Wallaceの明示的記述か、プロジェクト内で再現できる集計の根拠がある場合に限る。
5. 本文例を説明文に固定する前に、Wallaceの採用版・ページ・ギリシャ語本文を照合し、アプリ側の実解析候補と混同しない。

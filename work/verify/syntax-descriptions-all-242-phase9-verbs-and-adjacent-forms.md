# 第9段階：動詞48型と周辺品詞の優先監査

## 資料方針

主資料はWallace, *Greek Grammar Beyond the Basics* および *The Basics of New Testament Syntax*。動詞の時制・相・法・態は、形態だけから意味を機械的に決めるのではなく、Wallaceの定義、本文例、文脈、動詞の語彙的意味を照合する。公開資料： https://www.obinfonet.ro/docs/gk/resgk/wallace-basic-nt-greek.pdf

## 1. 動詞48型：最重要の監査課題

### A. 「時制形」と「意味上の読み」を混同しない

| 型群 | 現行説明のリスク | 改善方針 |
|---|---|---|
| 現在形：進行的・習慣的・反復的・格言的・歴史的・未来的 | 形態はすべて現在形だが、分類は相・談話機能・時間解釈を含む。時間副詞や語彙だけで決めると誤分類する。 | 「形態上の形」と「文脈で解釈される用法」をUI上で区別し、複数の読みが実際に競合するときのみ比較する。 |
| 未完了過去：進行的・起動的・反復的・習慣的・企図的 | 「未完了過去のデフォルト読み」「開始点を示す先行アオリスト」などを一般規則として扱いすぎる危険がある。 | 主動詞・語彙意味・物語の流れを確認。企図的・起動的などは、特定の動詞や文脈を根拠にする。 |
| アオリスト：総括的・起動的・結果到達・格言的・書簡的・劇的 | アオリストを単に「過去」または「一回」と説明するのは不適切。分類間の境界は文脈と語彙的意味に依存する。 | 「総括的」は動作を全体として提示する読みと説明し、単純な回数・過去時制と同一視しない。書簡的アオリストは書き手と読者の時間視点を確認する。 |
| 完了・過去完了：強意的・広延的・劇的 | 「完結した過去行為と継続的結果」などの説明が、完了の全例に当てはまる普遍規則のように読まれる危険がある。 | Wallaceの各サブタイプの定義・用例を照合し、形態自体が意味を一義的に決めるとは書かない。特に intensive/extensive の日本語名を説明で補う。 |
| 未来：予告的・命令的・審議的・格言的 | 未来形を常に未来時点とみなすと、命令・疑問・一般的真理の用法を取りこぼす。 | 文の種類、主語人称、引用・律法文脈、談話上の機能を手掛かりとして明示する。 |
| 法：勧告・禁止・審議・目的・条件・不定関係・可能性・祈願・間接話法 | 接続法・希求法の形と、節の構文機能が混在する。たとえば「目的節」は法形の名称ではなく節機能との組合せ。 | 「動詞形の用法」「節の機能」「談話上の意味」を別の軸として扱う。 |
| 命令法：継続・総括・起動・切迫・許容 | 現在命令＝常に継続、アオリスト命令＝常に総括と単純化する危険。 | アスペクトは解釈の手掛かりだが、文脈・動詞の意味・命令の種類を併せて判断する。切迫命令は時間副詞や呼格の共起だけで決めない。 |
| 態：能動・直接中動・再帰・相互・受動・許容受動 | 中動態の意味を、形態から一律に「自分自身に行う」と説明するのは危険。許容受動も受動形だけでは決まらない。 | 動詞の語彙的意味、構文、意味上の参与者を確認。稀用法・低頻度の断定には根拠を添える。 |

### B. 個別に優先修正すべき説明

1. `verb.imperative_customary`：「現在命令法＝継続・習慣」と機械的に結びつけない。Wallaceの用例・留保を確認して、アスペクトと命令の意味を分けて説明する。
2. `verb.imperative_constative`：「アオリスト命令のデフォルト読み」は、Wallaceが明示する範囲・意味を確認し、読者向けには「動作全体をひとまとまりとして命じる読み」と説明できるか検証する。
3. `verb.imperfect_ingressive`：「先行するアオリストが開始点を示す」は、全例に通用する必要条件のように書かない。
4. `verb.perfect_extensive`：「完結した過去行為とその継続的結果」は intensive と対比して説明し、単なる過去＋結果という単純公式にしない。
5. `verb.voice_middle_direct`：「稀用法」と例示の正確性を採用版で確認。中動態を単に再帰と同一視しない。
6. `verb.voice_passive`：「ὑπό + 属格で行為者が明示されると確度上昇」は形態・構文上の証拠であって、統語ラベルの正しさを保証する校正済み確率ではない。UIで確度数値を表示する場合は、そのスコアの意味を別途説明する。
7. `verb.declarative`：「独立節・非疑問のデフォルト用法」は他の意味分類と同じ階層に置くと、通常の直説法がほぼ常に競合候補になりやすい。分類体系上の役割と表示優先度を確認する。

## 2. 形容詞11型：構造と意味の混在

- `adjective.attributive` / `adjective.predicate` は形容詞の名詞句内の位置・述語機能に関する分類。
- `adjective.attributive_position` / `adjective.predicate_position` は位置パターンの構造標識であり、意味用法そのものと同じ軸ではない。
- `adjective.proper_adjective`（記述的用法）と `adjective.restrictive`（限定的用法）は、日本語の「限定的」という語が位置分類の「限定位置」と混同されやすい。表示名を見直し、「名詞句内の位置」と「意味上の限定機能」を分離する。
- `adjective.epithet` の「低確度候補」は、どの信号・しきい値に基づくかを内部仕様に結びつける。説明文だけで低確度と述べない。
- `adjective.genitive_complement` は形容詞の意味・項構造と属格補語の関係を示す。単なる形容詞の意味分類ではなく、依存関係に基づく構文分類として扱う。

## 3. 代名詞12型：語形・用法の区別

- `pronoun.personal` に `αὐτός` の人称用法を含める場合、同じ語形の強意用法・同一用法との区別が重要。語形だけで分類しない。
- `pronoun.intensive` / `pronoun.identical` は `αὐτός` の位置・冠詞構造が手掛かりになるが、位置パターンのみで意味を断定しない。
- `pronoun.interrogative` / `pronoun.indefinite` はアクセント・形態・文脈上の疑問／不定の機能を正確に処理する必要がある。表示にギリシャ語のアクセントが関係する場合、トークンデータがアクセントを保持しているか確認する。
- `pronoun.reciprocal` と `pronoun.reciprocal_emphasis` は、代名詞自体の分類と前置詞句による相互性の強調を混同しない。
- `pronoun.possessive_pronoun` は「所有代名詞」と「所有形容詞」の用語をWallaceの採用版に合わせ、品詞名を誤解なく表示する。

## 4. 主格10型・呼格5型

- `nominative.subject` / `nominative.predicate_nominative` は、冠詞の有無だけで主語と述語を決める規則として説明しない。Wallaceの主語判定の条件・例外・語順を確認する。
- `nominative.nominative_absolute` と `nominative.pendens` は、独立性と後続節の代名詞による再開という構造の違いを明確にする。
- `nominative.vocative_nominative` と `vocative.nominative_for_vocative` は実質的に近い名称・定義を持つ。異なる型として維持する理由をWallaceの分類と例で確認し、重複なら統合・軸分離の検討対象にする。
- `vocative.with_o` と `vocative.exclamatory` はどちらも ὦ を含む例を挙げているため、現行の定義では境界が弱い可能性がある。Wallaceの定義と実例を照合するまで、候補比較文を作らない。
- `vocative.chain` は複数の呼格が続くという構造記述で、個々の呼格の語用的機能とは別軸である。

## 5. 適用条件と残り

この段階は、動詞48型・形容詞11型・代名詞12型・主格10型・呼格5型について、Wallaceに照合すべき優先問題を整理した監査である。Wallaceの各ページと全本文例を逐一確認した完了判定ではない。次は冠詞・不定詞・対格・属格・与格・分詞以外の、節12型・前置詞7型・接続詞12型・小辞21型・名詞句構造12型・談話10型を重点的に確認する。

# 第5段階：与格の候補比較文案（手段・様態・領域・参照）

## 対象と結論

対象は `dative.means`（手段与格）、`dative.manner`（様態与格）、`dative.sphere`（領域与格）、`dative.reference`（基準／参照与格）。レジストリ記述とWallaceの参照節を確認し、読者向けの比較文案を作成した。ここでは特定のトークンの解析候補を取得していないため、「これらが同一箇所で同時候補になる」とは主張しない。

## 1. 候補の意味をどう区別するか

| 型 | 読者向けの中心質問 | 提案する説明 |
|---|---|---|
| 手段与格 | 何を使って／何によって行うのか | 与格が、動作を実現する手段・道具・媒体を示します。「〜によって」「〜で」と言い換えられることがあります。 |
| 様態与格 | どのように行うのか | 与格が、動作や状態の行われ方を示します。「どのように」と問い直すと意味を確かめやすくなります。 |
| 領域与格 | どの領域・分野で成り立つのか | 与格が、動作や状態の成り立つ領域・範囲を示します。「〜において」「〜の点で」と言い換えられることがあります。 |
| 基準／参照与格 | 何について、どの観点から述べるのか | 与格が、述語の内容を評価・説明する観点や基準を示します。「〜に関して」「〜の点で」と言い換えられることがあります。 |

領域与格と基準与格は、どちらも日本語で「〜の点で」と訳せる場合があるため、訳語だけで区別しない。文全体が示す「成り立つ範囲」なのか、「述語を評価・説明する観点」なのかを本文と構文から検討する。

## 2. 同時候補が実際にある場合の比較表示案

> **手段与格**なら、与格の語は動作を実現するために使われる手段・媒体を示します。  
> **様態与格**なら、動作がどのように行われるかを示します。  
> 見分けるには、単に「〜で」と訳せるかではなく、その語が「何を使って」と答えるのか、「どのように」と答えるのかを本文の関係から確かめます。

> **領域与格**なら、動作や状態がどの範囲で成り立つかを示します。  
> **基準／参照与格**なら、何について、どの観点から述べているかを示します。  
> どちらも「〜の点で」と訳せる場合があるため、日本語訳だけではなく、述語と与格句の関係を確認します。

これらはテンプレート案であり、実解析に同時候補があり、本文上の区別を説明できる場合にのみ表示する。根拠がなければ一般的な候補比較を表示しない。

## 3. 原典に基づく注意点

- Wallaceのレジストリ参照は、手段与格 §6.C.1、様態与格 §6.C.2、領域与格 §6.B.1、基準／参照与格 §6.A.4 と記録されている。実装前には採用版の見出し・ページを再照合する。
- Smyth §1450 は、ギリシャ語の与格が本来の与格に加え、失われた具格・場所格の機能も担うと説明する。これは古典ギリシャ語文法の背景説明であり、新約聖書の個々の箇所を自動判定する規則として使わない。
- Smyth §1455 は、動詞によって格の用法が変わり得て、単純な一般規則で一律に決められない点を指摘する。与格の意味分類は形態だけで決めず、述語・語彙・文脈を合わせて扱う。
- 「何によって」「どのように」などの質問は識別の補助であり、決定規則ではない。複数の言い換えが可能なことだけで複数の統語候補を確定しない。

## 4. 監査上の判定

- `dative.means` と `dative.manner`：説明は平易だが、短い日本語訳が重なり得る。実例で比較を検証する必要あり。
- `dative.sphere` と `dative.reference`：現行説明はどちらも「範囲／点」を含み、読者向けの区別が弱くなる可能性あり。例文を確認してから文言を確定する。
- レジストリの `alternatives` は関連型を示すにとどまり、当該トークンで両候補が発生する証拠ではない。
- この文書は説明案の作成まで。レジストリ、解析ロジック、UIは変更していない。

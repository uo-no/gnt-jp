## 2. 監査基準

1. **文法的正確さ** — Wallaceの分類・定義と整合するか。原典未照合の事項は「要原典確認」。
2. **読者への明瞭さ** — 専門用語を説明なしで使っていないか。
3. **識別性** — 近接する型との違いが説明から読み取れるか。
4. **具体性** — その用法が文中で何を表すか伝わるか。
5. **断定の強さ** — 文脈依存・議論のある解釈を一律の規則にしていないか。
6. **説明層の分離** — 読者向け定義と検出アルゴリズム向けヒントを混同していないか。
7. **例との整合性** — ギリシャ語例と日本語説明が適切に対応するか。

## 2. 各カテゴリの詳細確認

### カテゴリ A — Phase 1 添加切り詰め（52件）

**判定条件:** `addedText.length > 30`（+プレフィックス除去後のギリシャ語テキスト。JS `.length` = UTF-16 code units。ギリシャ語は全て BMP 内（< U+FFFF）のため codepoint と一致）

**生成形式:** `＋HEAD(20)…TAIL(4)（WIT・長文）`

| ID | 元テキスト（addedLen） | 生成 ja |
|---|---|---|
| MAT-0068 | `εὐλογεῖτε τοὺς καταρωμένους ὑμᾶς…`（66字） | `＋εὐλογεῖτε τοὺς καταρ…ὑμᾶς（RP・長文）` |
| LUK-0495 | `ἀλλὰ ῥῦσαι ἡμᾶς ἀπὸ τοῦ πονηροῦ`（31字、最短例） | `＋ἀλλὰ ῥῦσαι ἡμᾶς ἀπ…ροῦ（RP・長文）` |

**判定:** `長文` ラベルで「生成処理による切り詰め」と明示されている。元データとの混同リスクは低い。

### カテゴリ B — Phase 1 省略 lemText 切り詰め（14件）

**判定条件:** `lemText.length > 25`（apparatus.json の lemText 文字列の長さ）

**生成形式:** `lemText[:20]… の省略（WIT）`（`長文` ラベルなし）

| ID | lemLen | 元 lemText（先頭） | 生成 ja |
|---|---|---|---|
| MAT-0244 | 95 | `εἶπεν δέ τις αὐτῷ · Ἰδοὺ…` | `εἶπεν δέ τις αὐτῷ · … の省略（WH）` |
| MRK-0137 | 26（最短例） | `ἐποίησεν τοὺς δώδεκα , καὶ` | `ἐποίησεν τοὺς δώδεκα… の省略（Treg RP）` |
| ROM-0228 | 56 | `Ἡ χάρις τοῦ κυρίου ἡμῶν…` | `Ἡ χάρις τοῦ κυρίου ἡ… の省略（WH Treg NIV）` |

**問題点:** `…` に `長文` ラベルがないため、UI 上で「元データに省略表示がある（カテゴリ C）」と外見上区別できない。

### カテゴリ C — 元データ省略表示（70件）

**発生箇所:** apparatus.json の reading text 自体に `…` が含まれる  
`tokenRefStatus` 別: phrase 60件 / elision 7件 / verse_range 3件  
Phase 2/3 では除外条件 `e.readings.some(r => r.text.includes('…'))` により全件除外済み。

代表例:
```
MAT-0001 (phrase): Βόες … Βόες（WH NIV）・Βοὸς … Βοὸς（Treg）・...
MAT-0351 (phrase): τὸ … κλασμάτων ἦραν（WH Treg NIV）・ἦραν τὸ … κλασμάτων（RP）
MAT-0226 (elision): ἐξελθόντες δὲ οἱ Φαρισαῖοι … αὐτοῦ（WH Treg NIV）
```

**意味:** SBLGNT 校訂者が apparatus の表記として長い句を `…` で省略した（本文の省略ではなく、apparatus 誌面上の省略表示）。

### カテゴリ D — B + C の重複（4件）

4件（MAT-0244 / MAT-0560 / ROM-0228 / 1JN-0015）は:
- isOmission reading（lemText が省略される）を持ち、Phase 1 で処理済み
- 別の reading（非 isOmission）に元データ由来の `…` がある

Phase 1 は isOmission reading しか処理しないため、現在の ja 出力の `…` は lemText 切り詰め（カテゴリ B）由来。元データ `…` は出力に現れていない。

## 3. 長文除外の定義

### 判定対象

すべての閾値判定は **JavaScript `.length` プロパティ（UTF-16 code units）** で計測する。  
ギリシャ語テキストは全て BMP 内（U+0000–U+FFFF）のため、`.length` = Unicode codepoint 数と等価。証人ラベル（ASCII）も同様。

| 生成器 | 判定対象 | 閾値 | 判定変数 |
|---|---|---|---|
| Phase 1 添加 | `+` 除去後のテキスト（ギリシャ語のみ） | > 30字 | `addedText.length` |
| Phase 1 省略 | apparatus.json の `lemText` 全体 | > 25字 | `lem.length` |
| Phase 2 reading | apparatus.json の `reading.text` | > 30字 | `r.text.length` |
| Phase 3 reading | apparatus.json の `reading.text` | > 30字 | `r.text.length` |

**注意:** 閾値は `reading.text` のみを測定する。`（WIT）` 部分は ja 出力に加わるが、除外判定には含まれない。

## 4. 表示契約（UIに渡す方針）

現在、UI 表示は実装されていない。将来の UI 実装時に適用する契約を以下に定める。

### カテゴリ A — 添加切り詰め（52件）

**契約:** `長文` ラベルが存在する場合、`…` は生成処理による切り詰めを表す。元テキストは部分的にしか示されていない。

```
表示例: ＋εὐλογεῖτε τοὺς καταρ…ὑμᾶς（RP・長文）
意味: RP が RP によって添加される長文テキストの冒頭20字 + 末尾4字を示す。
```

**UI 推奨:** `長文` ラベルをツールチップまたは注記として表示する。`…` の前後を示すことで最低限の視認性を確保している。

### カテゴリ B — 省略 lemText 切り詰め（14件）

**現状の問題:** `…` に `長文` ラベルがなく、カテゴリ C（元データ省略表示）と外見上区別できない。

**将来の生成器への方針:**  
`の省略（WIT）` の前の `lemText` 切り詰め `…` には `（長文lem）` ラベルを付加する。

```
現在（問題あり）: εἶπεν δέ τις αὐτῷ · … の省略（WH）
推奨形式:         εἶπεν δέ τις αὐτῷ · … の省略（WH・長文lem）
```

**既存の apparatus-ja-auto.json は変更しない**（Task 33 の制約）。  
この方針は次回 Phase 1 を再生成する際または UI 実装時に適用する。

### カテゴリ C — 元データ省略表示（70件）

**現状:** Phase 2/3 から除外済み。いずれの自動生成 JSON にも含まれない。

**将来の生成方針（Phase N+1 で検討）:**  
元データの `…` をそのまま出力する場合は、`（原資料省略）` または `（SBLGNT 省略表示）` ラベルを付加する。

```
推奨形式（案）: τὸ … κλασμάτων ἦραν（WH Treg NIV・原資料省略）・ἦραν τὸ … κλασμάτων（RP・原資料省略）
```

元データの `…` は「テキストが存在するが apparatus に表示されていない」を意味し、テキストの省略（isOmission）ではない。UI がこれを「省略読み」として誤解しないよう、別フィールドまたはラベルで区別する。

現時点では除外を維持することが最も安全。

### カテゴリ D — B + C 重複（4件）

**現状:** Phase 1 の ja 出力には Category B の `…` のみが現れている（Category C の元データ `…` は出力されていない）。  
**契約:** 現在の 4 件の表示は Category B として扱う（Category B の問題が適用される）。

### 長文除外エントリ（Category E: 9件 / Category F: 98件）

**現状:** いずれの自動生成 JSON にも含まれない。

**将来の方針:** 長文読みを含むエントリは自動生成対象外のまま維持する。特に:
- JHN-0259（1,205字 — pericope adulterae 全文）
- ROM-0229（338字 — Romans doxology）

これらは手動注釈または専用フォーマットが適切。

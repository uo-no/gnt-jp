#### MAT-0013 — テキスト拡張・PLUS 非該当

| 項目 | 確認結果 |
|------|---------|
| lemText | 節の一部 |
| n=2 text | "τὸν υἱὸν αὐτῆς τὸν πρωτότοκον"（語数増加の差し替え） |
| "+" プレフィックス | なし |
| isOmission | false |

**判定: CONFIRMED**

n=2 は「+" 添加」ではなく「lem テキストより語数の多い代替読み」。
日本語補助で「追加（PLUS）」と記述するのは誤り（`修正必要`）。
正確な分類: `節構造差` または `語彙差`（句の拡張・語の増加）。

#### ROM-0051 — ἔχομεν / ἔχωμεν 形態差

| 項目 | 確認結果 |
|------|---------|
| n=1 [NIV RP] | ἔχομεν（直説法現在一人称複数） |
| n=2 [WH Treg] | ἔχωμεν（接続法現在一人称複数） |
| 語根 | 同一（ἔχω） |
| 文字コード | すべて Greek Block (U+03xx)、差異なし |

**判定: CONFIRMED**

法（mood）の差のみ。`形態差` タグが適切。
「直説法 = 確実な平和の宣言 / 接続法 = 平和を求める勧め」という解釈は原データに含まれない（`根拠不足`）。

#### 1CO-0246 — 三方向異読

| 項目 | 確認結果 |
|------|---------|
| n=1 [NIV] | καυθήσομαι（未来直説法、καίω「焼く」由来） |
| n=2 [Treg RP] | καυθήσωμαι（アオリスト接続法、καίω「焼く」由来） |
| n=3 [WH NA] | καυχήσωμαι（アオリスト接続法、καυχάομαι「誇る」由来） |
| 語根の差 | n=1, n=2 = καίω系（「焼かれる」）/ n=3 = καυχάομαι系（「誇る」） |
| 文字コード | すべて Greek Block (U+03xx) |

**判定: CONFIRMED**

n=1 と n=2 は同語根・異形態（時制・法の差）。n=3 は異語根（意味が根本的に異なる）。
日本語補助で語根の違いを述べることは事実に基づく（`確認済み`）。
「どちらが原典か」「どちらが神学的に正しいか」の記述は根拠不足。

#### JHN-0003 — μονογενὴς θεὸς / ὁ μονογενὴς υἱός

| 項目 | 確認結果 |
|------|---------|
| lemText | "μονογενὴς θεὸς"（語数: 2） |
| n=1 [WH Treg NIV] | "μονογενὴς θεὸς"（lem と同一） |
| n=2 [RP] | "ὁ μονογενὴς υἱός"（語数: 3、冠詞追加 + θεός→υἱός） |
| TEI XML 照合 | 行 78132-78138、完全一致 |

**判定: CONFIRMED**

差異は2点: (1) 冠詞 ὁ の有無、(2) θεός（神）↔ υἱός（子）の語彙差。
どちらも事実として記述可能。神学的含意（「どちらが高い位格論か」等）は根拠不足。

#### MAT-0458 — 節構造の差異 (MAT 19:17)

| 項目 | 確認結果 |
|------|---------|
| n=1 [WH Treg NIV] | "ἐρωτᾷς περὶ τοῦ ἀγαθοῦ; εἷς ἐστιν ὁ ἀγαθός" |
| n=2 [RP] | "λέγεις ἀγαθόν; Οὐδεὶς ἀγαθός εἰ μὴ εἷς ὁ θεός" |
| 語の差 | ἐρωτᾷς(尋ねる) vs λέγεις(言う)、ἀγαθοῦ(善いこと) vs ἀγαθόν(善い) |

質問の動詞（ἐρωτᾷς/λέγεις）および応答句の構造が異なる複合的差異。
`節構造差` タグが適切。「どちらがマルコ・ルカ並行記事と一致するか」等の記述は範囲外（`根拠不足`）。

## Task B — 表示タグ仕様

### B-1 タグ定義

apparatus-ja.json の `tag` フィールドに使用する7種のタグ。

| タグ | 定義 | 代表例 |
|------|------|-------|
| `形態差` | 同語根・異形態（法・時制・数・格・人称の違い） | ἔχομεν/ἔχωμεν（直説/接続）、καυθήσομαι/καυθήσωμαι |
| `語彙差` | 異なる語彙への代替 | θεός↔υἱός（JHN-0003）、λέγεις↔ἐρωτᾷς |
| `語順差` | 同語彙・異語順 | MRK-0392: リスト順序の入れ替え |
| `添加` | SBLGNT 本文にない追加テキスト（"+" で始まる reading） | MAT-0003、MAT-0008 |
| `省略` | 版によっては存在しないテキスト（isOmission=true） | （省略エントリ） |
| `表記差` | 同一語彙・異なる綴り（主に固有名詞） | Ἀσάφ/Ἀσά、Ἀμώς/Ἀμών |
| `節構造差` | 句・節全体の複合的差異（複数の変化が重なる） | MAT-0458（動詞・構文・応答句すべて異なる）、MAT-0013（語数増加の代替） |

### B-2 複合差異の扱い

複数の変化種別が1エントリに混在する場合（例: JHN-0003 は冠詞の有無 + 語彙差）:

- 支配的な差異の種別を `tag` に設定する。
- 詳細は `ja`（日本語補助テキスト）で事実として記述する。

例:
```json
{
  "tag": "語彙差",
  "ja": "冠詞の有無 (ὁ) + θεός(神)↔υἱός(子)"
}
```

「文意に影響する差異」を独立タグとして設けない。理由:
- どの差異が「文意に影響するか」は解釈判断であり、事実記述の範囲外。
- タグは差異の種別（何が変わっているか）を表し、影響度は表さない。

## Task C — 日本語補助 編集規則

### C-1 基本原則

Reading Japanese のL-0境界（翻訳しない・推論しない・解釈しない）をそのままこのデータに適用する。

日本語補助テキストは:

> **ギリシャ語の差異を構造的に記述するラベル**

であり、

> **翻訳・解釈・神学的評価・文脈補完ではない。**

### C-2 記述できること（確認済みの事実）

- 語形の差（「直説法↔接続法」「未来形↔アオリスト」等）
- 語彙の差（「θεός(神)↔υἱός(子)」等、語義は一語の指示にとどめる）
- 語順の差（「語順の入れ替え」）
- 追加・省略の有無
- 固有名詞の綴り差（「人名の綴り: Ἀσάφ / Ἀσά」）
- 節構造全体が異なること（「問いかけの構造が異なる」）

### C-3 記述してはならないこと

| 禁止事項 | 理由 | 例（禁止） |
|---------|------|----------|
| 全文翻訳 | 翻訳はL-0違反 | 「善い方はひとりです」 |
| 神学的解釈 | 根拠なし | 「高位格論を示す読み」 |
| 人物同定 | 推論 | 「族長アサフを指す」 |
| 異読の発生理由 | 不明・推論 | 「写本家が誤って読んだ」 |
| 写本証拠の評価 | データ範囲外 | 「古写本の支持が多い」 |
| 外部資料への参照 | 範囲外 | 「NA28 footnote 参照」 |
| 重要度・優先度の表現 | 解釈 | 「重要な差異」「より原典に近い」 |

### C-4 証人名表記

apparatus.json の witnesses フィールドの略称をそのまま使用する。
略称を勝手に展開・解説しない。

| apparatus.json の値 | 表示 |
|--------------------|------|
| `WH` | WH |
| `Treg` | Treg |
| `NA` | NA |
| `NIV` | NIV |
| `RP` | RP |
| `WHspur` | WHspur |
| `ECM` | ECM |

### C-5 確認状態の記録

| status 値 | 意味 |
|-----------|------|
| `確認済み` | apparatus.json の当該エントリと照合、事実として確認 |
| `要確認` | 記述根拠が不明確。表示前に再確認が必要 |
| `保留` | 編集方針が未決定。現行 UI には表示しない |

## Task D — apparatus-ja.json データ設計

### D-1 ファイル位置

```
public/assets/data/apparatus-ja.json
```

(apparatus.json と同ディレクトリ)

### D-2 スキーマ

```json
{
  "_meta": {
    "version": "1.0.0",
    "description": "SBLGNT Apparatus 日本語補助表示データ（人手編集）",
    "generatedAt": "YYYY-MM-DD",
    "policy": "L-0準拠 — 翻訳・推論・解釈を含まない事実記述のみ"
  },
  "entries": {
    "<apparatus-id>": {
      "tag": "<タグ（Task B の7種のいずれか）>",
      "ja": "<日本語補助テキスト（Task C の規則に従う）>",
      "status": "<確認済み | 要確認 | 保留>",
      "note": "<編集メモ（任意、表示しない）>"
    }
  }
}
```

### D-3 フィールド仕様

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `tag` | string | ✓ | Task B の7種タグのいずれか |
| `ja` | string | ✓ | 日本語補助テキスト（編集規則 C-2 に従う） |
| `status` | string | ✓ | `確認済み` / `要確認` / `保留` |
| `note` | string | — | 編集メモ（UI 表示しない） |

# Greek Verb Analyzer（ページ注入版）

閲覧中の聖書ページの右上に、解析パネルを直接表示する Chrome 拡張機能です。

## インストール
1. `chrome://extensions` を開き、右上の「デベロッパーモード」をON
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

## 使い方
- YouVersion / ともに聴く聖書 / BibleGateway は、ページを開くと自動でパネルが出ます
- それ以外のページは、ツールバーのアイコン（または Alt+Shift+G）で表示します
- もう一度アイコンを押すと非表示。パネルの ✕ でも閉じられます
- ヘッダーをドラッグで移動、右下の角でサイズ変更、「–」で折りたたみ
- ヘッダーの「◧」で分割ビューに切り替え（右端に固定し、ページ本体を左へ押し縮めます）。左端の境界をドラッグで幅を変更、「❐」でフローティングに戻ります
- 「同期ON」: ページのURLの聖句に自動で追従 / 「同期OFF」: 表示を固定
- タイトル（書名・章節）をクリックすると、書・章・節を選べます
- **単語のカードをクリックすると、下の統語論ペインに、その語の文中での役割（主語・属格の用法・分詞の用法など）がすぐ表示されます。** 別の語をクリックすれば切り替わり、◀ ▶ で節を移動しても表示は付いてきます（ペインは読み込み直さないので速い）
- 「**用例を表示**」で、その語の新約全体の用例を、パネルの中に一覧表示します（節をクリックするとその節へ移動。動詞は「同じ活用のみ」に絞り込めます）
- 統語論の結果は、スコアを前面に出さず、「**有力な解釈**」（競合がある時は「⚠ 別の解釈も有力です」、ほぼ拮抗の時は「有力な候補」＋「⚠ 別の読み方も十分考えられます」）で示します。内部の評価スコア（確率ではありません）は「詳細な評価」の中だけに表示します
- 統語論ペインの「用例」で、その語の新約全体の用例を一覧表示します。**用例の節名をクリックすると、その節へ移動し、用例の語を自動で選択します**（他の節での役割をすぐ比べられます）。「検索 ↗」は公開の検索ツールを新しいタブで開きます。ペインの ✕ で統語論を閉じると、従来の表示（語の詳細＋クリックで用例）に戻ります（詳細欄の「統語論」ボタンでまた表示できます）
- 「検索ツールで開く ↗」は、公開している検索ツールを新しいタブで開きます
- ◀ ▶ は章・書をまたいで移動します。パネルにフォーカスがある時は ←/→ キーも使えます
- 位置・サイズ・同期の状態は自動で記憶されます

## データを作り直す場合
`data/` は生成済みです。MorphGNT のデータを更新した時だけ:
```
node bundle.js        # bible_data/nt/*.json → morphgnt.json
node build-data.js    # morphgnt.json → data/*.json（書ごとの軽量版）と data/syn/<書>/<章>.json（統語論ビュー用）
```
## 対応サイトを増やす
`manifest.json` の `content_scripts.matches` にURLパターンを追加し、
`content.js` の `parsePageUrl()` に、そのサイトのURL形式の解析を足してください。

## 検索ツールのURL
用例検索は `content.js` 冒頭の `SEARCH_TOOL_URL` に開きます。公開している場所（現在は `https://bible-text.pages.dev/search-tool`）に合わせて書き換えてください。

## 統語論ビュー（syntax/）
`syntax/` は、統語論検索ツールを拡張機能の中で動かすためのものです。パネルが iframe で `syntax/syntax.html` を開きます。
- `syntax.html` / `syntax.js`: 元の `syntax-search.html` から、インラインJSとインラインのイベント属性（`onclick`）を分離したもの（Chrome拡張のCSP対応）。クリックは `syntax-boot.js` が `data-act` で振り分けます
- `syntax-analyzer.js` / `syntax-registry.json`: 解析エンジンと Wallace 分類の定義（元ファイルのまま）
- `book-master-ext.js`: 元の `book-master.js` の拡張機能版。`books.json` と `data/syn/` を読みます
- `css/`: **元の tokens.css / layout.css / components.css が手元に無かったため、見た目を推定した代替です。** 元のファイルがあれば `syntax/css/` に同名で上書きしてください
- 埋め込めないサイト（ページ側のCSPが拡張機能のiframeを禁止している場合）は、約5秒で「新しいタブで開く」に切り替わります
- 統語論ツールの内容を更新した時は、`syntax.html`（インラインJSを抜いた版）と `syntax.js` を作り直す必要があります

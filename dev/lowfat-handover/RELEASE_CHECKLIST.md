## 公開後チェックリスト

公開が許可され実行された後に確認する。**未実施の場合は空欄のままにする。**

### 起動・基本動作

- [ ] ページが正常に起動する（エラーなし）
- [ ] ブラウザーコンソールにエラーがない

### 編集モード

- [ ] 構造編集モードとレイアウト編集モードを区別して操作できる
- [ ] 構造編集モードでは語のドラッグで句の所属が変わる
- [ ] レイアウト編集モードでは語のドラッグで位置のみ変わり、構造は変わらない

### グループ移動

- [ ] グループ移動のドラッグが動作する（対象グループが縦移動する）
- [ ] ドラッグ中も操作が滑らか（フリーズしない）
- [ ] ドロップ後に下流グループへの押し下げが正常に反映される
- [ ] Undo で移動前の状態に戻る
- [ ] Redo で移動後の状態に戻る

### 保存・読み込み

- [ ] XML の保存で `rk-dy` 属性が出力される
- [ ] 保存した XML を再読み込みすると `rk-dy` が維持される
- [ ] 再読み込み後の語の座標がセッション中と一致する

### 回帰確認

- [ ] 通常の単語ドラッグ（位置変更）が従来どおり動作する
- [ ] ツリー操作（所属変更）が従来どおり動作する
- [ ] ズームが従来どおり動作する

## 3. G1573 ἐγκακέω — 個別 token 分析

### 語義概要

BDAG: "to be utterly faint-hearted, lose heart, behave badly"  
L&N 25.167: "to become so discouraged that one stops an activity"  
Thayer: "to be utterly spiritless, to be wearied out, to be faint-hearted"

語根の構造: ἐγ-（en = in/into） + κακ-（bad/ill） + -έω → 内側から弱まる、精神力が失われていく  
全6件が **μὴ と共起**（否定命令・禁止文脈）。

JA1955 訳語: 落胆する（4件）/ うみ疲れる（1件）/ たゆまずに＝たゆむ（1件）/ 失望する（1件）

---

### 3.1 LUK 18:1!13 — ἐγκακεῖν (V-PAN)

**Greek 文脈:**
```
δεῖν πάντοτε προσεύχεσθαι αὐτοὺς καὶ μὴ ἐγκακεῖν
```
「いつも祈るべきであり、かつ ἐγκακεῖν すべきでない」

**JA1955**: また、イエスは**失望せず**に常に祈るべきことを、人々に譬で教えられた。

**分析**: ルカはこのたとえを「祈りを続けること」の文脈で導入している。ἐγκακεῖν は祈りをやめること・気力を失うことを指す。「失望する」というより「くじける（祈り続ける意志が折れる）」のニュアンスが正確。V-PAN（不定詞）として δεῖν の補語位置。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける  
**確信度**: HIGH_ERROR / MEDIUM_LABEL

### 3.2 2CO 4:1!10 — ἐγκακοῦμεν (V-PAI-1P)

**Greek 文脈:**
```
ἔχοντες τὴν διακονίαν ταύτην καθὼς ἠλεήθημεν οὐκ ἐγκακοῦμεν
```
「この奉仕を受けているのだから（憐れみを受けた者として）、私たちは ἐγκακοῦμεν しない」

**JA1955**: このようにわたしたちは、あわれみを受けてこの務についているのだから、**落胆せず**に、

**分析**: パウロは使徒的苦難の中でも奉仕を継続する文脈。V-PAI-1P（現在直説法1人称複数）。「落胆しない」= 精神的に沈まない。外的苦難に直面しながらも内的に折れないという意味。「くじける」は精神力が折れることを表し、「落胆」より能動的・意志的な抵抗のニュアンスを含む。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける  
**確信度**: HIGH_ERROR / MEDIUM_LABEL

### 3.3 2CO 4:16!3 — ἐγκακοῦμεν (V-PAI-1P)

**Greek 文脈:**
```
Διὸ οὐκ ἐγκακοῦμεν ἀλλ εἰ καὶ ὁ ἔξω ἡμῶν ἄνθρωπος διαφθείρεται
ἀλλ ὁ ἔσω ἡμῶν ἀνακαινοῦται ἡμέρᾳ καὶ ἡμέρᾳ

**分析**: 2CO 4:1 と同一の語形・人称。「外なる人が滅びても内なる人は更新される」という対比の文脈。精神的に崩れない = くじけない。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける  
**確信度**: HIGH_ERROR / MEDIUM_LABEL

### 3.4 EPH 3:13!4 — ἐγκακεῖν (V-PAN)

**Greek 文脈:**
```
διὸ αἰτοῦμαι μὴ ἐγκακεῖν ἐν ταῖς θλίψεσίν μου ὑπὲρ ὑμῶν
```
「それゆえ、あなたがたのための私の苦難において ἐγκακεῖν しないよう求める」

**JA1955**: だから、あなたがたのためにわたしが受けている患難を見て、**落胆しない**でいてもらいたい。わたしの患難は、あなたがたの光栄なのである。

**分析**: V-PAN（不定詞）。パウロが獄中で読者にエフェソ書を送った文脈。読者が使徒の苦難を見て信仰的に崩れないよう願う。「落胆する」は気持ちが沈むこと全般だが、「くじける」は信仰・歩みの意志が折れることを強調する。「落胆」と「くじける」はどちらも成立する文脈。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける  
**確信度**: HIGH_ERROR / MEDIUM_LABEL

### 3.5 GAL 6:9!6 — ἐγκακῶμεν (V-PAS-1P)

**Greek 文脈:**
```
τὸ δὲ καλὸν ποιοῦντες μὴ ἐγκακῶμεν καιρῷ γὰρ ἰδίῳ θερίσομεν μὴ ἐκλυόμενοι
```
「善を行いながら ἐγκακῶμεν しないようにしよう。時が来れば、弱ることなく刈り入れるから」

**JA1955**: わたしたちは、善を行うことに、**うみ疲れて**はならない。たゆまないでいると、時が来れば刈り取るようになる。

**分析**: V-PAS-1P（現在能動仮定法1人称複数）。勧告的接続法（cohortative subjunctive）。隣接する μὴ ἐκλυόμενοι（弱らずに）と並置されており、疲弊・弛緩の文脈が強い。JA1955「うみ疲れる」は疲弊を強調。「くじける」は意志の折れを強調する点でやや異なるニュアンスだが、「善を行うことへの意志が折れる」という意味では成立する。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける  
**代替候補**: 〜たゆむ（2TH 3:13 と対応するが「たゆむ」は文語的）  
**確信度**: HIGH_ERROR / MEDIUM_LABEL（他の5件より「疲弊」ニュアンスが強い箇所）

### 3.6 2TH 3:13!5 — ἐγκακήσητε (V-AAS-2P)

**Greek 文脈:**

ὑμεῖς δέ ἀδελφοί μὴ ἐγκακήσητε καλοποιοῦντες
```
「兄弟たちよ、善を行うことにおいて ἐγκακήσητε しないように」

**JA1955**: 兄弟たちよ。あなたがたは、**たゆまず**に良い働きをしなさい。

**分析**: V-AAS-2P（アオリスト能動仮定法2人称複数）。禁止の aor subjunctive。テサロニケの文脈では「怠惰者」問題（3:6-12）の後に来る。「たゆむ」は弛緩・惰性化を表す文語表現。「くじける」は精神的圧力による挫折を含意。GAL 6:9 と同様に「善行の継続」文脈。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜くじける

## 4. G4823 συμβουλεύω — 個別 token 分析

### 語義概要

BDAG: "(1) to give advice, counsel someone (active) (2) to take counsel, consult with one another (middle)"  
L&N 33.307: "to advise, to give advice"  
語根: σύν-（together/with） + βουλεύω（to plan, deliberate） = "to deliberate together with"

**声（voice）による用法二分**:
- **能動態**: 一方向の助言・忠告（advise, counsel）
- **中動態**: 相互の協議・謀議（take counsel together, plot/conspire）

bible_data の4件 morph: V-AMI-3P（中動×2） / V-AAP-NSM（能動×1） / V-PAI-1S（能動×1）

---

### 4.1 MAT 26:4!2 — συνεβουλεύσαντο (V-AMI-3P)

**Greek 文脈:**
```
καὶ συνεβουλεύσαντο ἵνα τὸν Ἰησοῦν δόλῳ κρατήσωσιν καὶ ἀποκτείνωσιν
```
「そして、イエスを策略で捕え殺すために συνεβουλεύσαντο した」

**JA1955**: 策略をもってイエスを捕えて殺そうと**相談した**。

**分析**: V-AMI-3P（アオリスト中動直説法3人称複数）。σύν- prefix付き中動態 = 祭司長たちが互いに謀議する。ἵνα + 殺すという目的語から、敵意ある陰謀の相談。「相談する」は JA1955 の訳語で正確。「謀る」（目的を持つ謀議）も成立するが、chip label としては「相談する」が読者に分かりやすい。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜相談する  
**確信度**: HIGH_ERROR / HIGH_LABEL（JA1955 完全一致）

---

### 4.2 JHN 18:14!5 — συμβουλεύσας (V-AAP-NSM)

**Greek 文脈:**
```
ἦν δὲ Καϊάφας ὁ συμβουλεύσας τοῖς Ἰουδαίοις ὅτι συμφέρει ἕνα ἄνθρωπον ἀποθανεῖν ὑπὲρ τοῦ λαοῦ
```
「カイアファは以前、一人の人が民のために死ぬことが益になると、ユダヤ人たちに συμβουλεύσας した者であった」

**JA1955**: カヤパは前に、ひとりの人が民のために死ぬのはよいことだと、ユダヤ人に**助言した**者であった。

**分析**: V-AAP-NSM（アオリスト能動分詞主格男性単数）。能動態 = カイアファから ユダヤ指導者たちへの一方向の助言。τοῖς Ἰουδαίοις（ユダヤ人に）+ ὅτι 節（内容節）という構文は「〜に〜と助言する」の典型形。JA1955「助言した」は正確。「相談した」では相互性が含意されてしまい不正確。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜助言する  
**確信度**: HIGH_ERROR / HIGH_LABEL（JA1955 完全一致、能動態構文から一方向性が明確）

---

### 4.3 ACT 9:23!6 — συνεβουλεύσαντο (V-AMI-3P)

**Greek 文脈:**
```
Ὡς δὲ ἐπληροῦντο ἡμέραι ἱκαναί συνεβουλεύσαντο οἱ Ἰουδαῖοι ἀνελεῖν αὐτόν
```
「日数がかなり過ぎたころ、ユダヤ人たちはパウロを殺すために συνεβουλεύσαντο した」

**JA1955**: 相当の日数がたったころ、ユダヤ人たちはサウロを殺す**相談をした**。

**分析**: V-AMI-3P（アオリスト中動直説法）。MAT 26:4 と同一語形。ἀνελεῖν αὐτόν（彼を殺す）が目的。中動態 = 相互協議。JA1955「相談をした」は正確。MAT 26:4 と同じパターンで「〜相談する」が適切。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜相談する  
**確信度**: HIGH_ERROR / HIGH_LABEL（JA1955 完全一致）

---

### 4.4 REV 3:18!1 — συμβουλεύω (V-PAI-1S)

**Greek 文脈:**
```
συμβουλεύω σοι ἀγοράσαι παρ ἐμοῦ χρυσίον πεπυρωμένον ἐκ πυρὸς
ἵνα πλουτήσῃς καὶ ἱμάτια λευκὰ ἵνα περιβάλῃ...
```
「私はあなたに συμβουλεύω する。私から火で精錬された金を買いなさい。富むために。また白い衣を…」

**JA1955**: そこで、あなたに**勧める**。富む者となるために、わたしから火で精錬された金を買い…

**分析**: V-PAI-1S（現在能動直説法1人称単数）。語り手はキリスト（ラオデキア書簡）。σοι（あなたに）+ 不定詞（ἀγοράσαι）= 「あなたに〜するよう勧める」の構文。能動態で一方向的。JA1955「勧める」は「強く勧め・忠告する」のニュアンス。「助言する」は権威ある一方向の助言を表し、ここでも成立する。「相談する」は相互性を含意するため不適切。

**能動態の統一について**: JHN 18:14（助言）と REV 3:18（勧め）を比べると、JHN 18:14 は過去の助言を振り返る文脈（助言した者であった）、REV 3:18 は現在進行中の勧告。「助言する」はどちらも包含できる。「勧める」は JA1955 の選択だが、「助言する」は「（権威ある立場から）意見・判断を伝える」という意味で REV 3:18 にも適合する。

**判定**: CONFIRMED_ERROR  
**推奨 japanese**: 〜助言する  
**代替候補**: 〜勧める（JA1955 選択、REV 3:18 に文脈的により近い）  
**確信度**: HIGH_ERROR / MEDIUM_LABEL（「助言する」と「勧める」どちらも成立。「助言する」を選ぶのは能動2件の統一のため）

## 2. 監査フレームワーク定義

### A. JA1955との対応関係（各トークンに記録）

| 分類 | 定義 |
|------|------|
| `explicit` | JA1955節テキストに、このトークンに直接対応する独立した日本語表現がある |
| `implicit` | JA1955節テキストに独立した対応語はないが、日本語の文構造・語順・活用形・助詞等にトークンの意味が吸収されている |
| `none` | JA1955節テキストに対応する表現が確認できない |
| `uncertain` | 利用可能な情報では判定できない |

**記録根拠**: 節テキストと隣接トークン文脈を参照。文字列一致のみを根拠にしない。

### B. 現在の構造ラベルの妥当性（各トークンに記録）

| 分類 | 定義 |
|------|------|
| `適切` | 現在の括弧ラベルがそのトークンの文法的機能を正確に記述している |
| `修正候補` | 現在の括弧ラベルが誤っているか、別のラベルの方が正確である根拠がある |
| `判断保留` | 追加情報なしには妥当性を判断できない |

**区別**: 「JA1955に対応表現がある」ことは、ラベルが誤っている根拠にならない。

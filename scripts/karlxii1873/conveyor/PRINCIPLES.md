# RVR1909 対応表コンベヤ — 作成原則（パイロット ROM 1 で確定案）

WEB の PRINCIPLES.md を土台にしたスペイン語版。ROM 1 パイロットを運用し、
2026-11-07 にユーザーが承認して確定した。

## 形式
- 1章 = 1 spec ファイル `specs/<BOOK>-<CH>.py`（ROM 1 の spec が見本）。
- spec は辞書 SPEC： 節番号 → セグメント列。各セグメントは `(開始語, 終了語, トークン列|None, ノート|None)`。
  - 語の番号は、その節の RVR1909 本文を単一スペースで割った 1 始まりの通し番号。
  - トークン列は bible_data のその節内の tokenIndex。
  - セグメント列は節の全語を隙間なく・重なりなく覆うこと（build.py が検証）。
- build.py で JSON 化と検証： 「ALL CHECKS PASSED」になるまで直す
  （連結＝訳文一致、範囲外・重複なし）。
- 出力先（リポジトリ）: `public/assets/data/alignment/RVR1909/<BOOK>/<chapter>.json`

## 原則（スペイン語版）
1. **無理に対応づけない。** 曖昧ならトークンは未対応のままにする。
2. セグメントはスペイン語の語順どおり。連結すると訳文原文と完全一致する。
3. **冠詞**（el/la/los/las/un/una）は名詞のセグメントに同乗。ギリシャ語に冠詞トークンがあれば同じセグメントに入れる。前置詞の縮合形 **del（de+el）・al（á+el）** も同様に名詞側へ。
4. **主語代名詞・助動詞**：スペイン語は主語代名詞を落とすのが普通（pro-drop）で、その場合は注記不要。明示された代名詞（él、vosotros 等）は、対応するギリシャ語代名詞トークンで対応づける。動詞の形に含まれる主語は動詞のセグメントに同乗。
5. 前置詞は、対応するギリシャ語の前置詞（や格）のセグメントに入れる。与格は **á/al**、属格は **de** で表されることが多く、いずれも内容語のセグメントに同乗させる。訳語が複数語に広がる場合は句全体を 1 セグメントに。
6. **RVR1909 がビザンティン本文に従って補う語**（ギリシャ語本文に無い語）は tokens=None＋ノート。パイロットで確認した実例： 1:24 también（καί）、1:29 fornicación（πορνείᾳ）、1:31 implacables（ἀσπόνδους）。なお 1:16 は WEB と違い Χριστοῦ を補わない（RVR の本文に無い）。
6b. **置換型の異読**（RVR の語が、bible_data とは別のギリシャ語の語を訳している場合：
   例 10:17 θεοῦ↔Χριστοῦ、14:10 Χριστοῦ↔θεοῦ、16:5 Ἀχαΐας↔Ἀσίας）は、付加型と同じく
   None＋ノートとし、bible_data 側のトークンは未対応とする。誤った語義の対応
   （「Dios」に Χριστοῦ を当てる等）を作らないため。ただし代名詞の人称・数の
   読み違い（8:2 σε→me、15:7 ὑμᾶς→nos）は同一の指示対象のスロットとして、
   ノート付きで対応づける。
7. **節境界のずれ**は本文を動かさず対応表で吸収する： 食い込んだ句は None＋ノート、相手側の節ではそのトークンは未対応のまま。パイロットの実例は2件：
   - 1:9/10： 「siempre en mis oraciones」はギリシャ語本文では10節冒頭（πάντοτε ἐπὶ τῶν προσευχῶν μου）
   - 1:29/30： 「Murmuradores」はギリシャ語本文では29節末尾（ψιθυριστάς）。TR 系の節立てで30節冒頭に置かれる
8. 関係節化（τοῦ＋分詞 → El cual fué…）、慣用表現（me acuerdo = μνείαν ποιοῦμαι、se echan de ver = καθορᾶται）、迂言的な動詞訳（doy gracias = εὐχαριστῶ、es predicada、habiendo conocido、se hicieron fatuos）は、句単位のセグメントにしてノートで理由を短く残す。
9. 小辞（μέν 等）のうちスペイン語に現れないものは未対応でよい（ノート不要）。現れる場合（δέ → Mas、γὰρ → Porque / pues、τε → aun 等）は通常どおり対応づける。
10. ノートは日本語で簡潔に。規則 6・7・8 のケースには必ず付ける。
11. **接続代名詞の後接**： confirmaros（στηριχθῆναι＋ὑμᾶς の -os）や os deseo ver の語順のように、代名詞が動詞に付着・前置する場合は動詞のセグメントに両トークンを入れる。
12. USFM で **\add** と明示された訳者の補い（例： 1:1 の á ser）は、内容語のセグメントに同乗させ、ノートにその旨を書く。
13. RVR の括弧（1:3–4 の (que fué hecho … muertos)、1:13 の (empero…)）は訳文の句読点としてそのまま扱い、セグメント境界に影響させない。

  ROM 1 で全表示面サンプルを確認済み（2026-11-07、重複率は生サイドカーで 56.0%、
  PR #604/#612 の吸収策で語順ビュー・関係図は連続したスペイン語として読めることを確認）。

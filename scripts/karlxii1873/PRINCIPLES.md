# KARLXII1873 対応表コンベヤ — 作成原則（スウェーデン語版・パイロット ROM 1 で運用開始）

RVR1909 版 `conveyor/PRINCIPLES.md` を土台にしたスウェーデン語版。ROM 1 パイロットで運用し、ポポの確認後に量産へ入る。

## 形式（RVR1909 版と同じ）
- 1章 = 1 spec `specs/<BOOK>-<CH>.py`。SPEC: 節番号 → [(開始語, 終了語, トークン列|None, ノート|None), …]。
- 語番号は訳文（`public/translations/KARLXII1873/`）を単一スペースで割った1始まり、トークンは bible_data の節内 tokenIndex。
- `python3 scripts/karlxii1873/build.py BOOK CH spec out public` → ALL CHECKS PASSED が出荷条件。
- 出力: `public/assets/data/alignment/KARLXII1873/<BOOK>/<CH>.json`
- build.py の RVR1909 版からの差分は2点のみ（検証ロジックは不変）：参照パスと翻訳 ID、および「訳文に無い節（5節）は全トークン未対応の空セグメントで出す」適応。

## スウェーデン語固有の規則（スペイン語固有規則の差し替え）
S1. **定冠詞は名詞語尾**（-en/-et/-na/-ne 等：Apostlaämbete、Evangelium は無冠詞）で名詞と一体。分割しない。ギリシャ語の冠詞トークンは名詞のセグメントに同乗させる。前置される指示形 den/det/de（dens Guds…）は名詞句側に入れる。
S2. **不定冠詞 en/ett** は名詞（句）のセグメントに同乗。
S3. **前置詞**は対応するギリシャ語前置詞（や格）のセグメントへ。属格は af/om/till、与格は med/åt/dem 等の語順で表されることが多く、内容語のセグメントに同乗させる。
S4. **主語代名詞・助動詞**：スウェーデン語は主語代名詞を明示する（pro-drop でない）。ギリシャ語動詞の人称に含まれる jag/vi/han/de と助動詞 hafver/är は動詞のセグメントに同乗。動詞と離れて語順上同乗できない場合は、単独で None＋ノート（「動詞のセグメントと離れるため単独で未対応」）とする。
S5. **古い綴り・語形**（allom, dem, eder, Gudi, Herranom 等の与格・古形、-om/-ar 語尾）はそのまま語として扱い、語形の違いを理由に対応を変えない。
S6. **過去分詞・助動詞構文**（hafver … utlofvat、är … född）は一つのギリシャ語動詞に対する一つのセグメントにする。
S7. 属格・分詞句の言い換え（「som är om」「den född är」等の関係節化）は句単位のセグメントにしてノートで理由を残す。

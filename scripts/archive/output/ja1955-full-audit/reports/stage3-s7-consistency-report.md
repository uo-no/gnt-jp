## §6. 自動照合改善案（設計のみ・スクリプト改修なし）

### 検出可能性の整理

| 問題の種類 | 検出可能? | 現在の仕組み | 精度 |
|---|---|---|---|
| 同 Strong 同節反復 | ✅ | `sameLabel` フィルタ（`strong===self`） | 100% |
| クロス Strong 衝突（pool内） | ✅ | `sameLabel` フィルタ（`strong!==self`） | 100% |
| クロス Strong BL 衝突 | ✅ | `crossBL` フィールド（`BLACKLIST.has(sl.strong)`） | 100% |
| クロス Strong S4 衝突 | ⚠️ 部分的 | `crossBL` に S4 は含まれない | 未実装 |
| multiple occurrence（節内2回） | ✅ | `cntDirect > 1` | 100% |
| 帰属先の特定（どのトークンが JA1955 のどの語） | ❌ | 不可能 | — |
| 語義の妥当性（G18 vs G2570 等の意味的優先度） | ❌ | 不可能 | — |

### 改善提案 4件

#### IMP-1: SR 種別フラグ（`sr_type` フィールド）

**対象:** `analyzeToken()` の返却値に1フィールド追加  
**設計:**
```javascript
sr_type: "same_strong"        // 同Strong同節反復（cross なし）
       | "cross_strong_pool"  // cross-Strong で衝突相手が pool 内
       | "cross_strong_bl"    // cross-Strong で衝突相手が恒久 BL
       | "cross_strong_s4"    // cross-Strong で衝突相手が S4 除外 Strong
       | "mixed"              // same_strong + cross の複合（MAT 13:14 等）
```
**効果:** SR 73件（64件 same + 10件 cross - 1件 overlap）の内訳を定量化  
**コスト:** `analyzeToken()` に 5〜10行の追加のみ

---

#### IMP-2: クロス Strong 衝突マップの事前生成（`cross_strong_map.json`）

**対象:** pool 全体の前処理スクリプトに追加  
**設計:** 全 Strong ペアで同一 Japanese ラベルを持つ組み合わせを書巻別に列挙
```json
{
  "G2036|G3004": { "japanese": "言う", "books": ["JHN","ACT","MAT"], "instanceCount": 5 },
  "G18|G2570":   { "japanese": "良い", "books": ["MAT","LUK"],        "instanceCount": 3 }
}
```
**効果:** 衝突リスクの高い Strong ペアを事前把握し、人的確認の優先度設定に利用可能  
**注意:** 「同一書巻内」での列挙は false positive を含む（「同一節」のみが真の衝突）

---

#### IMP-3: BL/S4 衝突を SR カウントから分離する集計モード

**対象:** サンプル集計ロジック  
**設計:**
```
公式 SR（現行）= same_strong + cross_strong_pool + cross_strong_bl + cross_strong_s4 + mixed
参考値（BL/S4除外）= same_strong + cross_strong_pool + mixed
```
**効果:** 「除外済み Strong との共存」と「pool 内トークン同士の真の衝突」を分離して管理  
**前提条件:** 「BL/S4 との衝突は SR カウントするかどうか」のポリシー決定が必要

---

#### IMP-4: 位置順ベースの帰属推定（実験的・精度保証なし）

**対象:** duplicate_label 発生時の補助推定  
**設計:** 節内の globalIdx 順で「n番目のトークン → JA1955 の先頭から n番目の同表現」と仮定  
**効果:** duplicate_label の一部を「provisional explicit」として扱い、SR 率の解釈補助に利用  
**限界:** JA1955 の語順がギリシャ語に忠実であることが前提。倒置・強調構文では成立しない。精度検証なし。

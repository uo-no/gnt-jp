## 2. S7（中頻度 Strong 13,103件）の層設計

### 2.1 設計方針

単純な頻度帯分割ではなく、**意味機能・監査難易度・JA1955 対応の安定性**を軸に5つのサブ層を設定する。

### 2.2 S7 サブ層定義

| 層 | 名称 | 品詞 | Strong数 | トークン数 | 推奨サンプル |
|----|------|------|----------|-----------|-------------|
| S7a | 機能語（前置詞・副詞・小辞等） | prep, adv, particle | 23種 | 1,106件 | **34件**（3%） |
| S7b | 動詞 | verb | 35種 | 1,622件 | **82件**（5%） |
| S7c | 名詞（S1-S3外） | noun | 144種 | 8,566件 | **343件**（4%） |
| S7d | 形容詞・代名詞 | adj, pronoun | 33種 | 1,734件 | **87件**（5%） |
| S7e | その他・未分類 | other, particle（残余） | 3種 | 75件 | **8件**（10%） |
| **S7 計** | | | **238種** | **13,103件** | **554件** |

### 2.3 各サブ層の特性と監査留意点

**S7a — 機能語（1,106件）**

前置詞・副詞・小辞は JA1955 との対応が比較的安定している。ただし接続詞類似語は G2532（`auto_validation_excluded`）と同様のリスクに注意。節内複数回出現が起きにくいため SR 率は低いと予想。サンプリング率 3% で妥当。

**S7b — 動詞（1,622件）**

語義・活用形の多様性が最大。「語幹の共通性」により containsBase() は通過できても、JA1955 が別の活用形（「言う」→「言った」「言われた」等）で対応している場合、kanji match になる。implicit（漢字間接マッチ）が増えると予想。サンプリング率 5%。

**S7c — 名詞（8,566件）**

S7 最大層（65.4%）。固有名詞（地名・人名）は信頼度高。抽象名詞・多義語は要確認。節内に同じ名詞が複数回出現（同一トピックの反復言及）で SR 発生あり。書巻偏りが大きい（LUK・MAT・ACT・JHN が上位）。書巻×Strong の組み合わせで層化抽出。サンプリング率 4%。

**S7d — 形容詞・代名詞（1,734件）**

形容詞は修飾名詞との対応で節内重複が起きうる（「大いなる神・大いなる主」等）。代名詞 2種（G3778=この, G5100=ある等）は指示先の多様性に注意。σύ/αὐτός と同様の duplicate_label リスクを確認する。サンプリング率 5%。

**S7e — その他・未分類（75件）**

wordClass='other' 3種のみ。少数なので全件または高率サンプリングを推奨。

**22.8%**（295/1,295）。書巻によって 0〜61% と大きく異なる。一括ブラックリスト化は採用しない。

第1群合計: **397件（全体の 30.7%）**

- SR率だけで「自動照合不可」と判断しない。同一書巻内でも explicit なケースが多数存在する。
- 第1群でも explicit は 20〜60件あり（1JN: explicit=20/62=32%）。explicit は確認済みとして扱う。
- 「神の国」「神の御子」等の複合表現で「神」が単独トークンとして扱われているかを確認する。

## 4. 17件不一致の解消

### 4.1 原因（token ref 単位で確認）

**原因: G4674（σοῦ属格・S4 Strong）の census_count=17（<20）による二重計上。**

```
設計.cjs の S6 pool 計算: allPoolTokens.filter(t => census_count(t.strong) < 20)
  ← S1-S5 の除外なし

G4674 の census = 17（<20） かつ pool = 17件
  → S6 pool に G4674 の 17件が混入

一方、S4 pool にも G4674 の 17件が含まれる（G4674 ∈ S4_STRONGS）

設計.cjs: S4.pool(1423含む) + S6.pool(6741含む) = 重複カウント 17件
今回確定: 排他的割り当て（S4 > S6 優先）→ S6=6,724
```

### 4.2 照合結果

| 数値 | 件数 | 方法 |
|------|------|------|
| 初回報告 S6 | 6,741 | design.cjs（census<20、S1-S5除外なし）|
| 今回確定 S6 | **6,724** | pool内件数<20、definedStrongs除外あり |
| 差 | **17** | G4674（census=17）の S4/S6 重複分 |

### 4.3 等式検証（token ref 単位）

```
S1(1,423) + S2(3,065) + S3(1,338) + S4(723) + S5(1,843)
+ S6(6,724) + S7a(1,106) + S7b(1,622) + S7c(8,566) + S7d(1,734) + S7e(75)
= 28,219 ✓

層間重複（同一 token ref が複数層）: 0件 ✓
未分類トークン: 0件 ✓
```

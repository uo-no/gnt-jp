### 1.3 構文レジストリとの二層構造

`syntax-registry.json` には **二層** が存在する：

**第一層：接続詞トークン層**  
`conjunction.subordinating_content` → ὅτι（全用法）  
`conjunction.coordinating_explanatory` → γάρ

**第二層：節構造層（カテゴリ "clause"）**  
`clause.substantival_hoti` = 内容節（ὅτι・名詞的）  
`clause.causal_hoti` = 理由節（ὅτι・副詞的）

---

**`clause.causal_hoti` の定義（registry から抜粋）：**

```
id: clause.causal_hoti
label_ja: 理由節（ὅτι・副詞的）
description_ja: ὅτι で導かれ、主節の出来事の理由を示す節。
detection: ὅτι + 前方に発話・認識動詞なし
example: MAT 5:3 「μακάριοι οἱ πτωχοὶ τῷ πνεύματι, ὅτι αὐτῶν ἐστιν ἡ βασιλεία」
```

つまり **causal ὅτι の区別は設計上 "clause" 層に存在** している。`token.japanese` は第一層（接続詞タイプ）を表し、第二層（節の意味的役割）は別の場所で管理されている。

### 2.3 MEDIUM 58件内の偽陽性問題（`english="that"` + `ln="89.33"` = 19件）

```
1CO 1:12!4: λέγω δὲ τοῦτο [ὅτι]
```

- 前文脈: `λέγω(mean) δὲ τοῦτο(this)` — 説明的 τοῦτο + ὅτι 構文
- 後文脈: `ἕκαστος ὑμῶν λέγει Ἐγὼ...` — "各自が言っている内容"
- JA1955: 「はっきり言うと、あなたがたがそれぞれ...と言い合っていることである。」
- **理由節マーカー（「なぜなら」等）なし**

**判定**: これは **CONTENT ὅτι**（τοῦτο を解説する付加節）。LN 89.33 はこのトークンについて **不正確に付与** されている。スクリプトが causal/MEDIUM と分類したのは **誤分類**。

## 6. 最終所見

### 6.1 現行ラベル体系の正確な定義

> **「括弧付きラベルは、接続詞トークンの語彙的クラスを示す読者向け補助表記であり、  
> 当該接続詞が「主として」導く節の種類を lemma レベルで表す。  
> トークンごとの意味的機能（causal vs. content）の区別は clause 層で管理する。」**

これが現行設計の整合的な解釈である。

### 6.2 G3754 438件のラベル変更が必要かどうか

**変更を必要としない論拠（設計との一貫性）：**
1. 全 G3754 を `"［内容語句］"` にするのは lemma-level 設計の一貫した適用である
2. causal/content の区別は既に `clause.causal_hoti` / `clause.substantival_hoti` で設計されており、重複不要
3. G5613（ὡς）が比較・時間用法も含めて `"［内容語句］"` になっているのと同様の扱い

**変更する論拠（γάρ との一貫性）：**
1. γάρ（等位・説明）→ `"［理由語句］"` であるのに、subordinating causal ὅτι → `"［内容語句］"` は意味的対称性を欠く
2. 読者から見て「理由節を導いているのに内容語句ラベル」は誤解を招く

### 6.3 変更する場合、`"［理由語句］"` が適切か

適切ではあるが注意点がある：
- `"［理由語句］"` は γάρ（等位・説明接続）が主たる使用例
- causal ὅτい は **従属**接続詞
- 同じラベルで等位と従属の両方を指すことになる（既存 γάρ との性質の違いが失われる）

代替案: 新ラベル `"［理由節］"` を設計する（`"語句"` = 等位接続子、`"節"` = 従属接続子の区別）

### 6.4 変更しない場合、意味的区別をどこに保持すべきか

`syntax-registry.json` の `clause.causal_hoti` に既に保持されている。読者向けの補足情報として「ὅτi の理由節用法」の説明を UI の観察文（observation）または学習パネルに追加することが代替手段となる。

### 6.5 G5613・G2443・G1437 に同じ設計判断が必要か

| Strong | 問題規模 | 優先度 |
|--------|---------|--------|
| G5613 ὡς | 357件（様態） + 55件（時間） = **412件** のラベル不整合 | **高い**（G3754 causal より大きな意味的乖離） |
| G2443 ἵνα | 129件（補文 content ἵνα）のラベル不整合 | 中程度 |
| G1437 ἐάν | 62件（不定関係・時間不定）の軽微な不整合 | 低い |

G5613 の 357件（「like/as」= 様態比較）が `"［内容語句］"` というのは、G3754 の causal 問題より直感に反する。G3754 の設計判断と連動して G5613 の扱いも再検討する必要がある。

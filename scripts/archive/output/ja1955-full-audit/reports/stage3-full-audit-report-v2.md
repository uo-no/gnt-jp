## 7. S7e サンプル Wilson 95% CI 修正

v1 報告書に記載の "[2.1%, 40.2%]" は誤り。  
全件監査 S7e（n=75, k=22）の Wilson CI [20.2%, 40.4%] と数値が混入したものと推定する。

**正しい計算（n=8, k=1, p=0.125, z=1.96）:**

```
center = (0.125 + 1.96²/(2×8)) / (1 + 1.96²/8)
       = (0.125 + 0.2401) / (1 + 0.4802)
       = 0.3651 / 1.4802
       = 0.2467

margin = 1.96 × √(0.125×0.875/8 + 1.96²/(4×64)) / 1.4802
       = 1.96 × √(0.01367 + 0.01501) / 1.4802
       = 1.96 × 0.16935 / 1.4802
       = 0.2242

lower = 0.2467 − 0.2242 = 0.0224 ≈ 2.2%
upper = 0.2467 + 0.2242 = 0.4709 ≈ 47.1%
```

| 対象 | n | k | SR率 | Wilson 95% CI |
|---|---|---|---|---|
| S7e サンプル | 8 | 1 | 12.5% | **[2.2%, 47.1%]** |
| S7e 全件 | 75 | 22 | 29.33% | [20.2%, 40.4%] |

全件 SR（29.33%）はサンプル CI [2.2%, 47.1%] 内に収まる。  
v1 で掲載していた "[2.2%, 47.1%]"（最終サンプル報告書 `stage3-s7-final-sample-report.md` の値）が正。

## 8. none = 0 の解釈（限定付き）

**Stage 3 の pool は `matchType=direct` または `matchType=kanji` のトークンに限定して抽出している。**

none = 0件は「Stage 3 の抽出対象内で JA1955 との照合が完全に取れなかったトークンが存在しなかった」ことを意味する。

以下は本結果の範囲外:
- matchType が設定されない（未照合）トークン
- BL 3,922件（pool 外で除外済み）
- S4 暫定除外 723件（照合対象外）
- NT 全体の未対応トークンが存在しないこと

**none = 0 は NT 全体の完全対応を証明するものではない。Stage 3 の抽出設計の範囲内での結果である。**

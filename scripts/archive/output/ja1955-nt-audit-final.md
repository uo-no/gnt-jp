## 4. スクリプト限界と補正

### 4.1 G1161（[転換語句]→また）— 候補303件の信頼性

**問題**: スクリプトは「JA1955節テキストに"また"を含む」で判定。節に複数δέトークンがある場合、
どのtokenが"また"に対応するか区別できない。

**調査結果**:
- 単独δέ節（節内にG1161トークンが1つ）: **225件** → 高信頼（"また"が当該tokenに対応する可能性が高い）
- 複数δέ節（節内に複数のG1161トークン）: **36節・78件** → 低信頼（偽陽性を多く含む）

**補正判定**: 全303件を「要確認」とする。
節-token対応の確認なしに一括変更は不可。高信頼225件も、token位置とJA1955内「また」の位置の
照合が必要。

現状値が `[転換語句]` (表示なし) のため、変更後の効果が大きい。慎重な個別確認を推奨。

### 4.2 G1939（欲望→欲）— 偽陽性1件

**問題**: JHN 8:44 — JA1955テキスト「その父の欲望どおりを行おうと思っている」に、
`欲望` が含まれるため、その部分文字列として `欲` もヒット。
スクリプトは `verseHasBefore(欲望)=true` でも非保守ルールでは候補と判定してしまう。

**補正**: JHN 8:44!10 は偽陽性。  
**実質有効候補: 28件**（29件→28件）。JHN 8:44を除く28件はJA1955に「欲」「欲情」「情欲」等を確認。

### 4.3 G5088（産む→生む）— 候補0件

**問題**: `containsBase('生む')` は活用形 `生み`、`生まれ` を検出できない。
JA1955は birth context で主に `生れる`（他動詞ではなく自動詞）を使用。

**調査結果（G5088 全18件内訳）**:
- 現状維持5件: `産む` が明示的にJA1955にある → 維持正しい
- 要確認13件のうち:
  - JA1955に「産」がある: **8件** → JA1955も産む系、変更不要
  - JA1955に「生」がある: **5件** → JA1955は `生れる` 系（生まれる/生れた）。`生む` (他動詞) ≠ `生れる` (自動詞)。変更不可。

**補正**: G5088はパイロットのJAS 1:15（欲が孕んで「罪を生む」）に限り適用が正しい。
他のNT箇所では誕生文脈でJA1955が `産む` か `生れる` を使用。`生む` への変更は不適切。
**実質NT全体の追加候補: 0件。** パイロットのみ。

### 4.4 G4815（捕らえる→はらむ）— 候補0件

**問題**: JA1955の `はらむ` (妊娠) に対し、スクリプトが活用形 `はらんで` 等を検出できない。

**調査結果（G4815 全16件内訳）**:
- **捕える文脈**: MAT 26:55, MRK 14:48, LUK 22:54, JHN 18:12, ACT 1:16, 12:3, 23:27, 26:21 (8件)  
  → JA1955: `捕える` → 変更不要（現在値 `捕らえる` は正しい）
- **妊娠文脈**: LUK 1:24 (みごもり), LUK 1:31 (みごもって), LUK 1:36 (宿しています), LUK 2:21 (受胎) (4件)  
  → JA1955: `みごもる`/`宿す`/`受胎` → `はらむ` とは異なる。変更不可。
- **魚を捕る文脈**: LUK 5:7, LUK 5:9 (2件) → JA1955: 捕まえる文脈
- **その他**: PHP 4:3 (1件) → JA1955: `書きとめられ` (全く別の意味)
- **現状維持1件**: JAS 1:15（パイロット適用済み → 正しい）

**補正**: G4815のルール（捕らえる→はらむ）はJAS 1:15の特定文脈のみ有効。
NT他箇所では適用不可。**追加候補: 0件。**

### 4.5 G658（完成する→熟する）、G1828（引き出す→引く）— 候補0件

- G658 (apoteleo): NT2件のみ。LUK 13:32の1件はJA1955で「成就する」と訳されており変更不要。

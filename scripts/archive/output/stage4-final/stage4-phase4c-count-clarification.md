| 区分 | 実測値 | 推定値 | 未確認 |
|------|-------:|-------:|-------:|
| FUNCTION_CONFIRMED（個別確認） | 224件 | — | — |
| FUNCTION_CONFIRMED（推定） | — | 2,270件 | — |
| TRANSLATION_ABSORBED | 218件（実測） | ~2,420件（推定） | — |
| TRANSLATION_EXPLICIT | ~4〜6件（実測） | ~60〜80件（推定） | — |
| CONFIRMED_ERROR | 0件 | — | — |

この推定が成立する根拠:
1. G3756 / G3361 は形態論的に negation particle として分類済み（morph = PRT-N）
2. `japanese = "〜ない"` が 2,494件で 100% 均一
3. 224件のサンプル中 FUNCTION_MISMATCH = 0件
4. 62件の全件確認（小規模カテゴリ）で FUNCTION_MISMATCH = 0件

**CONFIRMED_ERROR = 0件 / REVISION_CANDIDATE = 0件** の結論は変わらない。  
ただし、「全件個別確認済み」ではなく「サンプル + Strong単位確認からの推定」であることを今後の参照で留意すること。

## 6. FUNCTION_CONFIRMED の区別（Phase 4d 追記）

本節は Phase 4d 準備作業の一環として 2026-10-31 に追記した。

### 6.1 個別確認 224 件の内訳

| 区分 | tokens | 意味 |
|------|-------:|------|
| **全件確認**（全 token を個別に照合） | **62** | 該当用法の mother population 全体が small enough（≤45件）のため全件確認した |
| **用法別サンプル確認** | **162** | zone-stratified サンプリングで無作為選択し個別に照合した |
| **個別確認合計** | **224** | |

- **62件の全件確認**の内訳: G3756 + 不定詞（8）+ 命令法相当（4）+ 接続法（4）= 16件、G3361 + 直説法（45）+ 希求法（1）= 46件
- **162件の用法別サンプル確認**の内訳: 残りの zone-stratified サンプル（G3756: 83−16 = 67件、G3361: 141−46 = 95件）

### 6.2 未確認 2,270 件の性質

| 区分 | tokens | 根拠 |
|------|-------:|------|
| **Strong 単位確認 + サンプル結果に基づく推定** | **2,270** | morph=PRT-N 均一性 + japanese均一性 + サンプル内エラーゼロから推定 |

未確認 2,270 件について「個別に確認した」ことにはならない。「個別確認した 224 件に誤りがない」という事実から、同じ Strong の残りのトークンにも誤りがないと **推定している** にすぎない。

### 6.3 FUNCTION_CONFIRMED の 2 種の意味

| 表現 | 適用範囲 | 意味 |
|------|---------|------|
| `FUNCTION_CONFIRMED`（実測） | 224 件 | bible_data + JA1955 を個別照合して機能を確認済み |
| `FUNCTION_CONFIRMED`（推定） | 2,270 件 | Strong 単位確認とサンプル結果から推定。個別確認はしていない |

報告書や監査 JSON で "FUNCTION_CONFIRMED" と記載されている場合、**個別確認済みとは限らない**。確実に個別確認済みといえるのは 224 件のみ。

### 6.4 CONFIRMED_ERROR = 0 / REVISION_CANDIDATE = 0 の適用範囲

| 項目 | 値 | 適用対象 |
|------|----|---------|
| `CONFIRMED_ERROR` | **0** | **個別確認した 224 件について** エラーなし |
| `REVISION_CANDIDATE` | **0** | **個別確認した 224 件について** 修正候補なし |

**「未確認 2,270 件に誤りがない」ことは保証しない。**  
CONFIRMED_ERROR = 0 という表現は「確認した範囲でエラーゼロ」であり、「全件エラーゼロが確定した」ことではない。

将来 Group C の個別確認件数を拡大した際に、現在の推定と異なる結果が出る可能性は排除できない。

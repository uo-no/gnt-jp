## 4. 現行 japanese 値の評価

### 4.1 "〜である" は CONFIRMED 誤り

`japanese = "〜である"` は εἰμί（to be）の構造ラベルとして Group B に使用されているラベルである。

G756（ἄρχομαι）の語義は「始める（to begin）」であり、"〜である" は語義的に完全に誤りである。

**誤りの性質**: 語義の誤りではなく **ラベル割り当て誤り**（データマッピングエラーの可能性が高い）。

### 4.2 構文パターンの確認（CONFIRMED）

全 84 tokens が次の構文パターンに従う:

```
G756（ἄρχομαι + 時制/態/人称/数） + 不定詞（主動作を表す）
```

例:
- `ἤρξατο κηρύσσειν` → "宣べ伝え**始めた**"（MAT 4:17）
- `ἤρξαντο τίλλειν` → "摘み**始めた**"（MAT 12:1）
- `ἤρξατο διδάσκειν` → "教え**始めた**"（MRK 4:1）
- `ἤρξαντο λαλεῖν` → "語り出した"（ACT 2:4）
- `Ἀρχόμεθα πάλιν...συνιστάνειν` → "また自己推薦をし**始めているのか**"（2CO 3:1）

例外的用法（不定詞なし）:
- `ἀρχόμενος ὡσεὶ ἐτῶν τριάκοντα` → "宣教をはじめられたのは年およそ三十歳" — G756 が「開始点」を示す分詞用法（LUK 3:23）
- `ἀρξάμενος ἀπὸ τοῦ βαπτίσματος` → "ヨハネのバプテスマの時から始まって" — 起点を示す用法（ACT 1:22）

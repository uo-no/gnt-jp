## 1. G863の基本訳語は何か

**基本訳語は存在しない。G863は複数の独立した意味クラスを持つため、単一の訳語では網羅できない。**

| 意味クラス | 件数 | 代表訳語 | 典型例 |
|-----------|------|---------|--------|
| A: forgive/pardon（赦免） | 47 | 赦す（変更なし） | MAT 6:12 罪を赦す |
| B: leave/remain（離去・残存） | 59 | 残す/去る/残される | MAT 4:20 網を残す |
| C: allow/let（許可・容認） | 37 | 許す/去らせる/黙認する | MRK 10:14 子どもを許す |

Cluster A（47件）は現在の`赦す`が正確であり変更対象外。B+C（96件）が今回の変更対象。

## 2.「去る」と「残す」を区別する基準

### 基準：直接目的語の意味的性質

| 状況 | 訳語 | 判断根拠 |
|------|------|---------|
| ①直接目的語が具体的な物・財産・役割（網・舟・家・すべて） | **残す** | 目的語が「残る」ことが意味の核心。他動詞「残す」が項構造に合致。 |
| ②主語（人・自然現象）が場所・人の前から立ち去る | **去る** | 主語の出発が意味の核心。自動詞的な離脱。 |
| ③直接目的語が人で、主語の出発が核心 | **去る** | 「悪魔が去る」「パリサイ人が去る」等。目的語は残されるが「去る」の方が自然。 |

### 具体的な分類例

```
残す：MAT 4:20 ἀφέντες τὰ δίκτυα（網を残す）
       MAT 5:24 ἄφες τὸ δῶρόν（供え物を残す）
       JHN 4:28 ἀφῆκεν τὴν ὑδρίαν（水がめを残す）
       MAT 19:27 ἀφήκαμεν πάντα（すべてを残す）

去る：MAT 4:11 ἀφίησιν αὐτὸν ὁ διάβολος（悪魔が去る）
      JHN 4:3  ἀφῆκεν τὴν Ἰουδαίαν（ユダヤを去る）
      JHN 16:28 ἀφίημι τὸν κόσμον（世を去る）
      MRK 8:15 ἀφῆκεν αὐτὴν ὁ πυρετός（熱が去る）
```

## 3.「捨てる」と「放つ」はどの意味領域で使うか

### 捨てる（9件）

**意味域**: 人・関係・義務・信仰を見捨てる（desert/forsake/abandon）。感情的・意志的な放棄。

| 用例タイプ | 例 |
|-----------|-----|
| 人を裏切り/見捨てて逃げる | MAT 26:56 弟子全員が逃げてイエスを捨てた |
| 神の戒めを捨てる | MRK 7:8 神の戒めを捨てて人間の言い伝えを守る |
| 羊を見捨てて逃げる | JHN 10:12 雇い人が羊を捨てて逃げる |
| 人を孤立させる（否定文） | JHN 8:29 私を一人にしなかった（捨てなかった） |
| 孤児のように見捨てる（否定文） | JHN 14:18 あなたがたを孤児として捨てない |
| 自然な欲求を捨てる | ROM 1:27 自然な関係を捨てた |
| 最初の愛を捨てる | REV 2:4 最初の愛を捨てた |

**捨てる vs 去る の境界**: 捨てるは「放棄」の意志・感情を伴う。去るは中立的な出発。

### 放つ（2件）

**意味域**: 物理的な「放出/解放/発声」。

| 用例 | 参照 |
|------|------|
| ἀφῆκεν τὸ πνεῦμα（霊を放つ）= 息を引き取る | MAT 27:50 |
| ἀφεὶς φωνήν（声を放つ）= 叫ぶ | MRK 15:37 |

**放つ vs 捨てる の境界**: 放つは物理的放出（声・息）。捨てるは関係・義務の放棄。

## 4.「許す」はどの意味クラスに対応するか

**許す（32件）**: Cluster C-allow — 許可・容認・放任。

| 構文パターン | 意味 | 例 |
|------------|------|-----|
| ἄφες / ἄφετε + inf（命令形） | 「〜させなさい」「〜することを許せ」 | MRK 10:14 子どもを許せ |
| ἀφίημι + 対格 + inf | 対象が〜することを許す | MAT 3:15 こうさせてください |
| 否定形 μὴ ἀφίημι | 〜を許さない | MRK 7:12 もはや何もしてはならないと |

**「許す」と「黙認する」の境界**:
- 許す: 積極的な許可（permit/let）
- 黙認する: 対処せずに容認する（tolerate/look the other way）→ REV 2:20のみ

## 5. 態・主語・目的語によって日本語表現を変える必要があるか

**結論: はい。特に受動形と主語の種類で変える必要がある。**

| 文法カテゴリー | 影響 |
|--------------|------|
| 受動形（V-PPI/V-APS/V-FPI） | 残す → **残される**（主語が残される側）|
| 主語=自然現象（熱・病） | 去る（「熱が去る」慣用句）|
| 目的語=物（網・家・すべて）, 能動 | 残す（他動詞）|
| 目的語=場所（ユダヤ・世界） | 去る（「ユダヤを去る」「世を去る」）|
| 目的語=人, B-abandon文脈 | 捨てる（放棄・見捨て）|
| 目的語=人, 中立的出発 | 去る（出発が核心）|
| C-divorce文脈（婚姻解消） | 去らせる（使役：相手を去らせる）|

## 6. 1CO 7:11–13のような文脈では、どのように訳語を決めるか

**原則: 同一の発話単位で同一動詞が対称的に使われる場合、訳語を統一する。**

| 問い | 答え |
|------|------|
| 7:11/7:12は夫が妻を去らせる → 去らせる | ✓ |
| 7:13は妻が夫を去らせる → 去らせる（同一動詞） | ✓（パウロの対称語法を反映） |
| 「去らせる」が使役に聞こえる問題は？ | 「強制的な追い出し」と誤解される余地があるが、古代の婚姻解消文脈では「解除する/手放す」のニュアンスが主。許容範囲内。 |
| 代替案「去る」（妻が去る）は正確か？ | 不正確。ἀφίημι は他動詞で目的語（τὸν ἄνδρα）を取る。「去る（自動詞）」では目的語との関係が失われる。 |

**一般化**: C-divorceのように社会的・制度的文脈（婚姻・法的行為）でἀφίημιが使われる場合、その文脈特有の訳語（去らせる）を一貫して使用する。文内で主語が変わっても訳語を変えない。

## 7. 訳語方針の限界

1. **JHN 8:29 / JHN 14:18**: 「一人にしない」「孤児として残さない」は捨てる（否定）で処理できるが、捨てるの正の形（捨てる）が強すぎる印象を与える可能性がある。代替として「見捨てる」も候補だが、現行lexiconにない。
2. **ACT 14:17**: 二重目的語構文（「自分を証しなく残した」）は残すで処理できるが、日本語の単語一語では構造が見えにくい。
3. **HEB 6:1**: 「初歩の教えを去る（移行する）」は去るで処理できるが、「残す」とのニュアンス差は最小。
4. **G863の多義性の根本**: ἀφίημι は古代ギリシャ語で「送り出す・手放す・解放する」という広義の「離去」を核義とし、そこから許可・赦免・遺棄まで広がる。日本語は動詞が細分化されているため、一対一対応は不可能。**訳語は文脈別に設計され、語義の核心を表示する。**

## 3. 語義的背景：なぜ全件 "〜である" になったか

Group B は εἰμί（to be）の述語構造ラベル "〜である" をグループラベルとして使用する。  
G680 / G1573 / G567 / G4823 / G566 は、bible_data に "〜である" ラベルが割り当てられているため、グループ割当アルゴリズムによって Group B に自動的に配置された。

しかしこれらは εἰμί 系の動詞ではなく、語義が完全に異なる動詞である（ἅπτομαι = touch, ἐγκακέω = lose heart, ἀπέχομαι = abstain, συμβουλεύω = consult, ἀπέχω = suffice）。これらは G756 ἄρχομαι と同様に、bible_data 初期割り当て時の ラベル誤適用と推定される。

## 3. 用法別詳細確認（Stage C-B）

### 3.1 G3756_ou_me_emphatic — οὐ μή 強調否定（G3756 側：112 tokens）

**確認数**: 16 件（zone-stratified）

**概要**: οὐ μή は二重否定による**強調否定構文**（決して〜ない）。G3756 と G3361 が連続または近接して使われる。接続法アオリストと組み合わさることが多い（οὐ μή + V-AAS）。

**代表サンプル（JA1955）**:
- MAT 5:18: "すたることはなく" (`παρέλθῃ[V-2AAS-3S]`)
- MAT 26:29: "決して...飲むことをしない" (`πίω[V-2AAS-1S]`)
- JHN 10:28: "いつまでも滅びることがなく" (`ἀπόλωνται[V-2AMS-3P]`)
- HEB 13:5: "決してあなたを離れず" (`ἀνῶ[V-AAS-1S]`)
- REV 3:5: "決してしない" (`ἐξαλείψω[V-FAI-1S]`)

**判定**: FUNCTION_CONFIRMED / TRANSLATION_EXPLICIT（"決して" などの強調語が JA1955 に出現）

**NOTE**: "〜ない" ラベルは οὐ の基本否定機能を表すが、強調力（"決して"）は単独では表現しない。οὐ μή 組み合わせ全体として強調が成立する。これは **設計上 by design**（stage4-negation-design.md §2.3）。

---

### 3.2 G3361_imperative_prohibition — μή + 命令法禁止（154 tokens）

**確認数**: 16 件（zone-stratified）

**代表サンプル（JA1955）**:
- LUK 6:37: Μὴ κρίνετε → "人をさばくな"（V-PAM-2P）
- JHN 2:16: μὴ ποιεῖτε → "商売の家とするな"（V-PAM-2P）
- MAT 28:10: Μὴ φοβεῖσθε → "恐れることはない"（V-PNM-2P）
- ROM 12:2: μὴ συσχηματίζεσθε → "この世と妥協してはならない"（V-PNM-2P）
- LUK 11:7: Μή πάρεχε → "面倒をかけないでくれ"（V-PAM-2S）

**判定**: FUNCTION_CONFIRMED / TRANSLATION_ABSORBED

**NOTE**: JA1955 の "〜するな" / "〜してはならない" は命令形（verb form）+ 禁止助詞によって構成される。"〜ない" ラベルは否定の機能的構成要素として機能しているが、日本語的な禁止表現（〜するな）はラベルと動詞読みの**組み合わせ**から生まれる。"〜ない" 単独では自然な禁止表現にならない（「行くない」は非文）。ただし、これは **構造ラベルの性質上の制約**であり、ラベル誤りではない。

## 5. 否定の作用域（Scope of Negation）に関する観察

### 5.1 作用域の設計上の扱い

stage4-negation-design.md §4 の方針に従い、否定の作用域は「否定 token の Reading Japanese」の問題ではなく、**否定される動詞/形容詞側 token の問題**として扱った。

### 5.2 作用域が特定されにくい事例（NOTED）

以下の構文では、否定の作用域が文脈に依存する。

| パターン | 代表例 | 作用域 |
|---------|-------|-------|
| 二重否定（οὐδείς + οὐ） | JHN 10:28 "奪い去る者はない" | οὐδείς が主否定 |
| 焦点否定（強調位置） | JHN 6:38 "自分の心のままを行うためではなく" | 目的節全体 |
| μὴ μόνον...ἀλλά | JHN 13:9 "足だけではなく" | 対照構造の一部 |

これらはいずれも "〜ない" ラベルの問題ではなく、文節・節構造の問題。Stage 4 の記録として NOTED のみ。

### 5.3 二重否定（Double Negation）

NT ギリシャ語の「二重否定」は**強化否定**（否定 + 否定 = より強い否定）であり、論理的な肯定に転化しない。

- οὐ μή（強調否定）: 確認済み（上記）
- οὐκ...οὐδείς / μή...μηδείς: 否定複合代名詞との組み合わせ（Group D G3761/G3366 が主体）
- G3756 + G3361 の連続: οὐ μή のパターンに含まれる

二重否定の Group C での独立した問題は確認されなかった。

# Stage 4 Group C 否定表現機能監査設計

生成日: 2026-10-31  
対象: Group C — G3756（οὐ/οὐκ/οὐχ）+ G3361（μή）の adv-classified tokens  
件数: 2,494 tokens（G3756 = 1,543 adv tokens / G3361 = 951 adv tokens）

---

## 1. Group C の位置づけ

### 通常の内容語監査（Group A）との分離

Group C は通常の内容語 Strong 単位語彙審査（Group A）に**含めない**。

理由:
- οὐ/μή は語彙的意味（辞書的な語義）を単独では持たない。否定の機能を提供する
- 「言う」「持つ」などの content word のように Strong 単位で「正確な日本語訳語」を確定する審査ではない
- 監査の問いが異なる: 「このラベル "〜ない" は当該 token の否定機能を適切に表しているか」

### 現状維持の一律判断はしない

Group C は「すべて現状維持」とは判断しない。以下の問題が起き得る:
- "〜ない" ラベルが適切でない用法（文脈上の省略・強調・二重否定）の見逃し
- class=ptcl や class=conj で分類された G3756/G3361 tokens（Group Z に分類済み）との整合性
- JA1955 での表現が "〜ない" から大きく乖離するケース

## 2. Group C の実態

### 2.1 強 Strong 別実件数

| Strong | ギリシャ語 | class | adv tokens (Group C) | 非adv tokens (Group Z) | 合計 |
|--------|---------|-------|---------------------|----------------------|------|
| G3756 | οὐ/οὐκ/οὐχ | adv(1543) + ptcl(80) | **1,543** | 80 | 1,623 |
| G3361 | μή | adv(951) + ptcl(57) + conj(34) | **951** | 91 | 1,042 |
| **合計** | | | **2,494** | 171 | 2,665 |

> **注**: G3756 の ptcl(80) と G3361 の ptcl(57)+conj(34) = 171 tokens は bible_data で adv 以外の class に分類されており、Group Z（機能語）に割り当て済み。これらは Group C の監査対象外。

### 2.2 G3756 と G3361 の機能差

| 点 | G3756（οὐ系） | G3361（μή系） |
|----|-------------|-------------|
| 主たる否定の場 | 直説法（事実の否定） | 接続法・命令法・不定詞・分詞（仮定・意志・期待の否定） |
| 強調形 | οὐχί (G3780) | μήτι (G3387) |
| 組み合わせ | οὐ μή（強調否定 = 決して〜ない） | μηδέ（nor, not even, μηδείς = nobody） |
| 疑問文 | 肯定回答を期待する否定疑問 | 否定回答を期待する否定疑問 |

### 2.3 "〜ない" ラベルの性質

"〜ない" は **構造的・機能的ラベル** であり、訳語ではない。このラベルが意味するのは:
- 「この token は直後（または節内）の動詞/形容詞を否定する」
- JA1955 では否定形動詞として表現される（言わなかった / 持っていない 等）

## 3. 監査設計（二段階）

### Stage C-A: Strong 単位の基本機能確認

各 Strong について確認する項目:

```
Strong: G3756
lemma: οὐ/οὐκ/οὐχ
function: 直説法否定
current_label: 〜ない
確認点:
  1. ラベル "〜ない" が基本機能（直説法の事実否定）を適切に表しているか
  2. "〜ない" ラベルで表しきれない用法があるか（組み合わせ否定など）
  3. JA1955 での代表的な表現パターン
basic_assessment: OK | NOTE | NEEDS_SAMPLE
```

### Stage C-B: token 単位の文脈確認（抽出サンプル）

Stage C-A で NOTE / NEEDS_SAMPLE となったケースについてのみ実施。

以下の状況を優先的にサンプル抽出する:

| サンプリング対象 | 理由 |
|----------------|------|
| οὐ μή の組み合わせ | 強調否定 = JA1955 で "決して〜ない" 等に強化される可能性 |
| 不定詞・分詞の否定（G3361） | μή + inf/ptc では "〜せずに" "〜ないように" 等の形になることがある |
| 命令法の否定 | G3361 + 命令法 = "〜するな" → "〜ない" ラベルが自然か |
| 否定疑問 | οὐ で始まる疑問 = "〜ではないか" → "〜ない" ラベルが自然か |
| 二重否定 | οὐδέ/μηδέ との組み合わせ |

## 4. 否定の作用域の扱い

「否定の作用域（scope of negation）」は token レベルで一義的に確定できない（文節構造に依存する）。

Stage 4 の方針: 作用域の確定は「否定 token の Reading Japanese」の問題ではなく、否定される動詞/形容詞側の token の問題として扱う。Group A の動詞監査で文脈確認する際に関連情報として記録するにとどめる。

---

## 5. JA1955 での否定表現パターン

確認すべき JA1955 の表現パターン:

| ギリシャ語の形 | 期待する JA1955 表現 | 確認観点 |
|-------------|-------------------|---------|
| οὐ + 動詞直説法 | 動詞否定形（〜なかった/〜ない） | 吸収・省略なし |
| μή + 接続法 | 〜しないように / 〜なければよい | 目的節・恐れ節との区別 |
| μή + 命令法 | 〜するな / 〜してはならない | 禁止命令 |
| μή + 不定詞 | 〜せずに / 〜しないように | 分詞句の否定 |
| οὐ μή + 接続法 | 決して〜ない | 強調否定 |
| οὐδέ/μηδέ | 〜もない / 〜でさえない | G3761/G3366 は Group D |

**監査の範囲**: 2,494 tokens（Strong 単位確認 2 件 + 用法別サンプル）

4. 命令法・不定詞の μή 用法サンプル — 5〜10 件

## 7. Group Z に分類された G3756/G3361 非 adv tokens との関係

G3756 の 80 ptcl tokens と G3361 の 91 ptcl+conj tokens は Group Z（機能語）に分類されている。

これらは bible_data で class=ptcl または class=conj として記録されているため Group C ではなく Group Z。

**確認事項（UNKNOWN）**: なぜ同一 Strong 番号でも class が異なるのか。bible_data の original source における class 判定の不一致と考えられるが、影響は軽微（171 tokens）。Stage 4 では記録のみ。

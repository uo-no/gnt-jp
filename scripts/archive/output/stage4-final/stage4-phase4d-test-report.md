## 4. Fisher-Yates 実装メモ

末尾から n 要素を選ぶ partial Fisher-Yates:

```javascript
for (let i = pool.length - 1; i >= pool.length - n && i > 0; i--) {
  const j = rng() % (i + 1);
  [pool[i], pool[j]] = [pool[j], pool[i]];
}
return pool.slice(pool.length - n);
```

この実装は:
- n < pool.length のとき末尾 n 要素に一様無作為な部分集合を配置
- i > 0 ガードで境界外アクセスを防止
- XorShift32 による modulo バイアスは母集団サイズ << 2³² の場合に実用上無視可能

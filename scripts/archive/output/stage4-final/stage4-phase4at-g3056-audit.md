## 2. 判定根拠

### 2.1 「申し開き」と判定する構文基準

以下の構文パターンを検出した場合、`APPROVE_MOSHIHIRAKI` とする。

#### パターン A: λόγον + ἀποδίδωμι (G591)

> `λόγον ἀποδίδωμι` = "申し開きをする / アカウントを返す"

ἀποδίδωμι（G591）は「返す・納める・清算する」の意。
`λόγον ἀποδίδωμι` は「言葉を返す＝申し開きをする」というイディオムで、
ROM 14:12 の `λόγον δώσει`（δίδωμι = G1325）とほぼ同義の申し開き表現。

#### パターン B: λόγον + αἰτέω / ἀπαιτέω (G154 / G523)

> `λόγον αἰτέω/ἀπαιτέω` = "申し開きを求める / アカウントを要求する"

αἰτέω は「求める・要求する」、ἀπαιτέω は「取り戻す・請求する」。
`λόγον αἰτοῦντι` = "あなた方に申し開きを求める者に" の形で現れる。

### 2.2 「ことば」を維持する原則

以下に該当する場合は `RETAIN_KOTOBA`：

| パターン | 例 |
|---------|-----|
| τὸν λόγον + 神・主の属格 | `τὸν λόγον τοῦ κυρίου` = 主のことば |
| τὸν λόγον + 指示代名詞 | `τὸν λόγον τοῦτον` = このことば |
| τὸν λόγον + 形容詞 | `εὔσημον λόγον` = 明瞭なことば |
| 伝達動詞の目的語 | δέχομαι / λαμβάνω / κρατέω + τὸν λόγον |
| 言葉・演説・説教文脈 | 文脈から speech/word と明確 |

### 2.3 ACT 1:1 特殊処理

`λόγον ποιέω（中動態）` = "著述する / 書く" という用法を `APPROVE_OTHER_GLOSS (著述)` として別分類する。
これは申し開き構文でも通常のことば用法でもない第三のパターン。

```

ἀποδώσουσιν (G591, V-FAI-3P) + λόγον: 未来形の申し開き。裁きの文脈で確実な APPROVE_MOSHIHIRAKI。

**LUK 16:2!13**
```
"τί τοῦτο ἀκούω περὶ σοῦ ἀπόδος τὸν λόγον τῆς οἰκονομίας σου"

```
ἀπόδος (G591, V-2AAM-2S) + τὸν λόγον + 属格: 主人が管理人に「申し開き」を命じる場面。

**ACT 19:40!17**
```
"κινδυνεύομεν ἐγκαλεῖσθαι στάσεως περὶ τῆς σήμερον μηδενὸς αἰτίου ὑπάρχοντος περὶ οὗ [οὐ] δυνησόμεθα ἀποδοῦναι λόγον περὶ τῆς συστροφῆς ταύτης"

ἀποδώσοντες (G591, V-FAP-NPM) + λόγον: 未来分詞形の申し開き、指導者の責任文脈。

## 5. APPROVE_OTHER_GLOSS 1件の詳細

### ACT 1:1!4 — 著述

```
"Τὸν μὲν πρῶτον λόγον ἐποιησάμην ὦ Θεόφιλε περὶ πάντων ὧν ἤρξατο ὁ Ἰησοῦς ποιεῖν τε καὶ διδάσκειν"
（テオフィロよ、わたしは以前の著述で、イエスが行いまた教え始めたすべてのことについて述べた）
```

**構文**: `λόγον ποιέομαι（中動態）` = "言葉を作る" ではなく "著述する・書く"

ルカ文書（ルカ福音書・使徒行伝）の二書構成における序文定型。
`ποιέομαι` の中動態は「自分のために作る = 著述する」意で、
「ことば」（speech/word）でも「申し開き」（account/defense）でもなく、
「著述（書物・記録）」という第三の語義が適切。

**判定根拠**: HIGH confidence（ルカ序文定型、語義・構文・文脈が一致）

## 1. 「5,348 件」が何を表すか

Stage 4 準備報告書が記した「内容語 tilde 5,348 件」は:

- **定義**: class∈{noun,verb,adj,adv,num} かつ `token.japanese` が "〜" で始まる token の count
- **数え方**: NT 内の Greek word token 1 件 = 1 件（verse count でも predicate structure count でもない）
- **旧値との差**: 旧報告の 5,348 はスクリプト計測の軽微な差異を含む。token ref 単位での再集計では Group B(2,369) + C(2,494) + D(377) = **5,240 tokens**
- **含まれるもの**: εἰμί 活用形（22 Strongs）+ 否定副詞（2 Strongs）+ その他構造ラベル動詞・副詞（16 Strongs）
- **含まれないもの**: pron tilde（Group G の関係代名詞 1,657 tokens）/ 機能語（前置詞・接続詞の tilde）

### 2.2 εἰμί の用法分類

| 用法 | 説明 | JA1955 での表現例 | 頻度予測 |
|------|------|-----------------|---------|
| **コピュラ** | X は Y である。述語形容詞/名詞との結合 | "神は愛である" / "大きい" (εἰμί 省略) | 最多 |
| **存在** | ～がある/いる。存在そのものを表す | "そこに人がいた" | 中 |
| **場所・状態** | ～にいる/ある。場所や状態を表す | "彼はエルサレムにいた" | 中 |
| **迂言的** | εἰμί + 分詞 = 迂言時制 | "洗礼を施して**いた**" (periphrastic progressive/perfect) | 中 |
| **同一性** | X is Y (identity statement) | "わたしは道である" | 少 |
| **JA1955 独立出現なし** | 日本語では述語に吸収される | 形容詞述語 "大きかった" (no explicit "であった") | 多 |

### 2.3 監査基準

**監査の目的**: "〜である" ラベルが当該 εἰμί トークンの Reading Japanese として適切かを確認する。用法を変えることが目的ではない。

```
Strong: G2076（ἐστίν, 3ps 現在, n=896）
用法別サンプル:
  コピュラ: ヨハ4:24 "神は霊である" → θεὸς πνεῦμά ἐστιν → JA1955: "神は霊である"  ✓
  存在: ヨハ11:25 "わたしは復活であり、命である" → ἐγώ εἰμι ἡ ἀνάστασις → "〜である" は適切か?
  迂言: ルカ13:10 "教えていた" → ἦν διδάσκων → 分詞が主語義を持つ, εἰμί は補助動詞
  吸収: マル12:26 "生ける者の神" → "〜である" は JA1955 では述語として独立しない

判定基準:
  OK: "〜である" が述語を示す構造ラベルとして機能している
  AMBIGUOUS: 述語構造か助動詞的用法か不明
  NOTE: JA1955 で全く別の形（吸収/省略）になっており、ラベルが誤解を招く可能性
```

### 2.4 迂言構造（periphrastic）の扱い

εἰμί + 現在分詞 / 過去分詞（例: ἦν + βαπτίζων）は:
- Stage 3 pool の分詞側（βαπτίζων）はすでに監査されている可能性
- εἰμί 側（ἦν）は補助動詞として独立した内容語義を持たない
- 判定: "〜である" ラベルを保持するが、迂言用法として NOTE を付ける

> **注**: G3756 と G3361 の残存 tokens には **plain-label tokens も存在する**（それぞれ 80 tokens および 91 tokens が Group A に分類）。これらは token.japanese が "ない" や別の plain 値を持つケース。

### 3.1 否定副詞の Reading Japanese 役割

"〜ない" ラベルは内容語ではなく**否定の機能的標識**として付与されている。

JA1955 の表現パターン:
- 動詞の否定形に吸収: "言わなかった", "持っていない", "来ない"
- 独立した否定: "ない", "いない"
- 二重否定: οὐ μή (強調否定) → JA1955 では "決して〜ない"

### 3.2 監査方針

**結論（推奨）**: Group C の 2,494 tokens は機能的構造ラベルとして現状維持。語彙的監査は不要。

ただし以下の例外を確認する:
1. plain-label の G3756/G3361 tokens（Group A に分類済み）— なぜ plain-label になっているか確認
2. 二重否定パターン（οὐ μή）— JA1955 が "決して〜ない" と強調しているか確認

### 3.3 G3756/G3361 の plain-label tokens（Group A 分類分）

G3756 の plain-label tokens: ~80 件。これらの `token.japanese` は "〜ない" ではない別の値を持つ。内容語 plain として Group A に含まれている。個別に何の値を持つか確認が必要。

## 7. 設計上の重要注意点

**「〜である」を日本語訳語として扱わない**

"〜である" は JA1955 の訳語（日本語の "〜である"）ではなく、**Reading Japanese の構造ラベル**（"このトークンは述語を形成する" という機能標識）である。

監査の問いは「"〜である" という日本語が適切か」ではなく:
- この εἰμί トークンに構造ラベルが必要か
- "〜である" は当該 εἰムί の機能（コピュラ/存在/迂言補助）を十分に示しているか
- JA1955 が全く別の形で処理している場合、Reading Japanese として誤解を生む可能性はあるか

**εἰμί 以外の述語構造**

ユーザー指示: "εἰμί の全出現を対象にするだけでなく、εἰμί 以外の動詞が述語構造に関与する場合も検討"

応答: Stage 4 の残存内容語（Group A: plain-label verb）には、述語動詞として機能する多くの動詞が含まれる（G3004 言う, G2192 持つ 等）。これらの動詞の述語機能は Group A の Strong 単位語彙審査で確認する。Group B の "εἰμί 述語構造" は「εἰμί が tilde ラベルを持つ特殊な述語用法」に限定しており、一般動詞の述語機能とは別問題として設計する。

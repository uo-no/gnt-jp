### 2.1 G3754 ὅτι（79 tokens）— 全件 OK

| 項目 | 値 |
|------|-----|
| lemma | ὅτι |
| gloss | that / because |
| class | adv（bible_data） |
| japanese | ［内容語句］（全 79 件） |
| verdict | **OK（79 件 / 79 件）** |

**機能**: ὅτι が adv として分類されている場合、次のいずれかの用法:
- **間接話法の that**: λέγω ὅτι = "say that" → ［内容語句］は該当節全体を「内容語句」として標識
- **因果の because**: ἐγένετο ὅτι = "because it happened" → 同上

bracket ラベル ［内容語句］ は、ὅτι が導く節が主動詞の内容的補語または因果節であることを示す構造ラベルとして適切。

**書巻分布**: JHN(24) / ACT(23) / ROM(13) / 1CO(9) / 1JN(9) / 2PE(4) / REV(7) / 他  
**代表例**:
```
JHN 6:29 θεοῦ ἵνα πιστεύητε → (G3754 ではなく G2443 の例、参照のみ)
JHN 13:33 οἴδατε ὅτι ζητήσετέ με → "あなたがたはわたしを捜し求める"
ROM 1:8   εὐχαριστῶ ... ὅτι ἡ πίστις → "信仰が語り伝えられている"
```

**用法②: 近似表現用法（15 件）** — ὡς + 数量詞 = "about X / approximately X"

```
ACT 1:15  ὡς ἑκατὸν εἴκοσι  →  "百二十名ほど"
ACT 4:4   ὡς χιλιάδες πέντε  →  "五千人ほど"
...（計 15 件）
```

**NOTE — 近似用法の ［内容語句］ 適用について**:  
近似表現用法の ὡς（ὡς + 数量詞）は「節を導く」のではなく「数量を近似的に限定する」副詞。この用法への ［内容語句］ ラベル適用は、節導入用法との意味的一貫性から見るとやや広いが:
- bible_data でこれらは class=adv と記録されており、bracket ラベルは構造的に一貫
- ラベル変更には別途設計判断が必要（Stage 4 の scope 外）
- CONFIRMED_ERROR ではなくデザイン上の決定として記録

**Stage 4 での扱い**: 現行ラベル維持。NOTE として記録。

## 3. bracket ラベル体系の評価

### 3.1 class=adv での bracket ラベル使用について

Group E の 4 Strongs は bible_data で class=adv と記録されているが、実質的に接続詞的機能（節を導く）を持つ。

| Strong | 主な辞書分類 | bible_data class | bracket ラベル |
|--------|------------|-----------------|---------------|
| G3754 ὅτι | 接続詞 (conj) | adv | ［内容語句］ |
| G5613 ὡς | 副詞 / 接続詞 | adv | ［内容語句］ |
| G2443 ἵνα | 接続詞 (conj) | adv | ［目的語句］ |
| G3704 ὅπως | 副詞 / 接続詞 | adv | ［目的語句］ |

**メタノート**: 同一 Strong 番号でも bible_data の class が conj の tokens は Group Z（機能語）に分類されており、adv の tokens のみが Group E に含まれる。class=conj の tokens は別問題として記録済み（stage4-count-reconciliation.md §3 参照）。

### 3.2 ［内容語句］ vs ［目的語句］ の適用基準

| ラベル | 適用基準 | 対象 |
|--------|---------|------|
| ［内容語句］ | 主動詞の内容的補語（that-clause）または因果節 | G3754, G5613 |
| ［目的語句］ | 目的・結果節（purpose/result clause） | G2443, G3704 |

現行適用は一貫しており、逸脱なし。

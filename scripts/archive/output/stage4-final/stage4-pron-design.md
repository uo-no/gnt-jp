# Stage 4 pron 独立監査設計

生成日: 2026-10-31  
対象: Group F (pron plain, 5,544 tokens, 46 Strongs) + Group G (pron tilde, 1,657 tokens, 3 Strongs) + Group H (G4671 未除外, 69 tokens, 1 Strong)  
合計: 7,270 tokens, 50 Strongs

---

## 1. pron 独立監査の根拠

代名詞は内容語（noun/verb/adj 等）とは監査要件が異なる。

| 要素 | 内容語 | 代名詞 |
|------|--------|--------|
| 語義の多様性 | Strong 単位で原則確定可 | 形態（格・数・性）と referent で変化 |
| JA1955 への照合 | 辞書形 vs 活用形の問題 | 主語省略・吸収の問題 |
| 現行ラベルの性質 | 辞書形ラベル（言う/持つ等） | 人称・参照対象ラベル（私/あなた等） |
| 監査単位 | Strong + 形態で概ね一括確認可 | 参照対象・文脈・用法が問題の核心 |

**S4 σύ 単数形方式（G4675/G4571/G4771/G4674）を pron 全体の自動除外ルールとして流用しない**。それは σύ 4 形が特定の Reading Japanese 課題（2人称単数の一括処理）に限定した先行処理であり、代名詞全般の語彙的監査とは設計が異なる。

### Group G — pron tilde（関係代名詞, 1,657 tokens, 3 Strongs）

| Strong | 語形 | n | ja |
|--------|------|---|-----|
| G3739 | ὅς/ἥ/ὅ (関係代名詞) | 1,408 | 〜する者 |
| G3748 | ὅστις | 139 | 〜する者 |
| G3745 | ὅσος | 111 | 〜するだけ |

**現行ラベルの性質**: "〜する者" は関係節を導く構造ラベルであり、JA1955 の訳語ではなく **関係代名詞の節構造が続くことを示す Reading Japanese 標識**。

**監査論点**:
- ὅς/ἥ/ὅ は性・数・格によって異なる形を持つが、JA1955 では関係節「〜する者/もの/こと」として処理される
- "〜する者" ラベルが適切かどうかは、節の先行詞（person vs thing vs abstract）によって変わる可能性がある
- G3745（ὅσος = "as much as/as many as"）の "〜するだけ" は程度・量を含む意味

**監査単位**: Strong 単位（3 Strongs は一括確認可能）。個々の token は先行詞の確認が必要な場合のみ抽出。

### Group H — G4671（σοί, 69 tokens）

**発見事項**: G4671（σοί, σύ の与格）は S4 除外セット {G4675, G4571, G4771, G4674} に含まれていない。S4 で除外されたのは σύ（主格）, σέ（対格）, σοῦ（属格）, σός（所有形容詞）の 4 形のみ。与格 σοί（G4671）は 69 tokens が残存。

**方針選択肢** (Stage 4 開始前に確定が必要):
1. S4 除外に追加して Stage 4 対象外にする（σύ 系統として一括処理）
2. Group F に統合して pron plain として監査する
3. 独立した監査対象として残す

推奨: σύ の格変化形という文法的位置から **S4 除外に準じる方針** を選択し、Group F から分離したままにする。ただし最終判断は人間確認が必要。

## 3. 監査の二段階設計

### Stage A: Strong 単位の基本語義確認

各 Strong について以下を確認する。

```
Strong: G####
lemma: Greek lemma
function: 人称 / 指示 / 疑問 / 不定 / 再帰 / 相互 / 関係
形態: 格変化の代表形
current_japanese: 現行 token.japanese
基本語義: 辞書的意味
JA1955_patterns: JA1955 での代表的な表現方法（明示/省略/吸収）
label_assessment: OK / AMBIGUOUS / CANDIDATE / NOTE
note: 備考
```

### Stage B: token 単位の文脈確認（ケース抽出）

Stage A で AMBIGUOUS / CANDIDATE / NOTE となった Strong のみ実施。

確認項目:
- 実際の語形（格・数・性）
- 文脈内の参照対象（先行詞 / discourse referent）
- JA1955 の該当箇所での表現
- 明示 / 省略 / 吸収の区別
- 現行 japanese ラベルの妥当性
- 判断根拠と確信度

## 4. JA1955 との照合方針

代名詞の JA1955 照合は内容語と異なる。

| 状況 | 判断 |
|------|------|
| JA1955 で代名詞が明示される（わたし/あなた/この等） | 対応確認可能 |
| JA1955 で主語省略（日本語の pro-drop） | ラベルは適切だが JA1955 に対応なし → "省略" と記録 |
| JA1955 で所有格が「私たちの〜」として名詞に吸収 | "吸収" と記録 |
| 指示代名詞が文脈上 "それ/これ" と別訳 | 個別確認 |
| 不定代名詞 τις が文脈上 "〜という人" 等 | 個別確認 |

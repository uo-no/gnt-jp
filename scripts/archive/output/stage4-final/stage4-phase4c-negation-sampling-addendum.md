## 2. 確認された設計不足

Phase 4c の実施指示（Section 2）では、少なくとも以下の用法層を独立して扱うことが求められた。

### 2.1 指示に含まれ、既存設計にない用法カテゴリ

| 指示カテゴリ | 既存設計 | 状態 |
|------------|---------|------|
| 通常の直説法否定 | 記載なし（暗黙的） | **不足** |
| 命令法・接続法における μή | 部分的（§3-2,3） | 部分的 |
| 不定詞・分詞に付く否定 | 部分的（§3-3） | 部分的 |
| οὐ μή による強調否定 | あり（§3-1） | OK |
| 二重否定・否定の重複 | **記載なし** | **不足** |
| 関係節・条件節・目的節内の否定 | **記載なし** | **不足** |
| 否定の作用域が文脈によって変わる用法 | §4 で言及のみ（サンプル設計なし） | **不足** |
| JA1955で否定が明示される用法 | §5 参照のみ（分類設計なし） | **不足** |
| 日本語構造に吸収される用法 | **記載なし** | **不足** |
| ギリシャ語に否定があるが日本語で明示されない用法 | **記載なし** | **不足** |

### 2.2 用法分類に関する技術的不足

#### (a) G3756 の非直説法用法が設計に含まれていない

既存設計は G3756 を「直説法否定」として扱い、以下の用法を想定していなかった。

- G3756 + 分詞（61 tokens = 4.0%）
- G3756 + 不定詞（8 tokens = 0.5%）
- G3756 + 接続法（4 tokens = 0.3%）
- G3756 + 命令法（1 token = LUK 22:26、3 人称禁止）

これらは実データに存在する。

#### (b) G3361 の直説法用法が設計に含まれていない

G3361 は「接続法・命令法・不定詞・分詞の否定」として設計されたが、実データで G3361 + 直説法が 45 tokens（4.7%）存在する。構文的理由：

- 条件文の前件（εἰ μή 構文の変形）
- μήγε（nor yet, μήγε + 直説法）
- 否定疑問文の特定構造

これは文法上正常であり、設計の想定外に実在する。

#### (c) 第2アオリスト活用形（V-2xxx）の処理設計が存在しない

morph コードに第2アオリスト prefix "2" が付く場合（V-2AAI / V-2AAS / V-2AAN / V-2AAP 等）、品詞単純分類では「mood code = verb[2] キャラクタ」の抽出が失敗する（V-2AAI の verb[2] = 'A' (voice) となり 'I' (indicative) を取れない）。

影響規模: G3756 で ~147 tokens (9.5%)、G3361 で ~126 tokens (13.2%) が "other_verb" に誤分類されるリスクがある。

実態: G3756_other_verb の 147 件は morph 分布から **大部分が第2アオリスト直説法**（V-2AAI: ~97件）であることが確認された。G3361_other_verb の 126 件は第2アオリストの接続法・分詞・不定詞（V-2AAS: ~50件、V-2AAP: ~13件、V-2AAN: ~13件、V-2ADO: ~15件）が主体。

#### (d) 否定疑問（negative question）のサンプル設計が形式化されていない

既存設計（§3-4）には「否定疑問 3〜5件」とあるが：
- 疑問文の検出方法（句読点 ";" の有無など）が定義されていない
- 疑問文内の G3756 と疑問文冒頭の G3756 を区別する方法が定義されていない

## 3. Phase 4c における追加設計（本監査で採用した方針）

### 3.1 用法カテゴリの拡張

既存の 4 カテゴリを以下の 10 カテゴリに拡張して監査を実施した。

| カテゴリID | 名称 | 対象 Strong | 検出方法 |
|-----------|------|-----------|---------|
| CAT-01 | 直説法否定 | G3756主、G3361従 | V-xAI / V-xPI / V-xFI / V-2xI morph |
| CAT-02 | 命令法禁止 | G3361主、G3756稀 | V-xAM / V-xPM / V-xNM morph |
| CAT-03 | 接続法 | G3361主、G3756稀 | V-xAS / V-xPS morph |
| CAT-04 | 不定詞否定 | G3361主、G3756稀 | V-xAN / V-xPN morph |
| CAT-05 | 分詞否定 | G3361主、G3756従 | V-xAP / V-xPP morph |
| CAT-06 | οὐ μή 強調否定 | G3756 + G3361 組み合わせ | 近接する G3756 + G3361 パターン |
| CAT-07 | 希求法 | G3361 稀 | V-xAO / V-xPO morph |
| CAT-08 | 動詞なし（near window） | 両 Strong | 8 token 以内に動詞未検出 |
| CAT-09 | 従属節（条件・目的） | G3361 + 直説法（45件）| 前後文脈から判定 |
| CAT-10 | 第2アオリスト各種 | 両 Strong | V-2xxx morph |

### 3.2 サンプル数の拡張

既存設計: 用法 4 種 × 5〜10 件 ≈ 20〜40 件  
本監査採用: 用法 10 カテゴリ × 4 書巻区（zone-stratified）× 4〜16 件 = **224 件**

### 3.3 JA1955 翻訳パターン分類の追加（既存設計にない）

実施指示に従い、以下の判定区分を追加した（既存設計の4区分に加え）。

| 翻訳区分 | 定義 | 適用 |
|---------|------|------|
| TRANSLATION_ABSORBED | 否定が日本語の動詞活用に吸収される（〜なかった等） | 多数 |
| TRANSLATION_EXPLICIT | 日本語に否定副詞が出現する（決して/いっさい等） | οὐ μή 等 |
| TRANSLATION_OMITTED | 日本語に否定が現れない | 稀 |
| UNCERTAIN | JA1955 対応が不明確 | 稀 |
